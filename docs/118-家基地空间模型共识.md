# 118. 家 / 基地 / 临时工作基地 空间模型共识

> 2026-11-11。MC 专家 × 点子王。  
> 触发：家唯一但地址簿出现两条同名“家”；基地/测试基地/未来临时工作基地概念需要定界。

## 1. 核心结论

```text
kind     保留为地点类别（兼容）
role     新增语义角色：home | base | outpost | test-base
radius   决策半径，不是硬边界
唯一性   靠 role 约束，不靠 name
```

家/基地不是“更大或更小的 kind”，而是玩家赋予的语义角色。

## 2. 尺寸

| 角色 | 建议范围 | 依据 |
|---|---|---|
| home | 6×6（radius 3） | 小范围归属；床/门/箱；回家判定 |
| base | 20×20（radius 10 / 半宽 10） | 刷怪抑制 24 格内、火把覆盖成本、leash 余量 |
| outpost/临时工作基地 | radius 6 | 临时作业点，带 TTL |

注意：

```text
安全来自封闭 + 光照，不来自半径本身
半径是决策/候选范围，不是禁止越界
```

## 3. 字段模型

```text
kind       原枚举，兼容
role       home | base | outpost | poi | test-base
radius     家 3 / 基地 10 / 作业点 6
bbox       基地可选矩形
parent     outpost → base id（弱引用，不维护树形一致性）
temporary / expireAt   以 game_time 为准
unique     home | test-base | null
isTest     夹具专用
dimension / createdBy / lastSeen / confidence
```

`radius=null` 不能继续当“点”用；未定义时保守降级并告警。

## 4. 唯一性

### 家

```text
同 dimension 只允许 1 条 active role=home
迁移 = 改指针 + 旧记录 retiredAt
绝不新增第二条“家”
```

当前 p1/p27 两条同名“家”是现成故障源：解析依赖遍历顺序，可能绑到 166 格外的老家。

### 测试基地

```text
isTest=true
unique='test-base'
生产决策默认排除 isTest
```

### 冲突处理

```text
同 role 冲突 → fail-closed
不自动选、不取第一条
报 ambiguous 或让玩家确认
```

## 5. 重叠 / 迁移

- base 允许 ≤3 个；
- 两个 base bbox 相交 >30% 或中心距 < 半径和 → 拒绝或合并；
- home 应在某个 base bbox 内；在外则告警但允许；
- 迁移前建议新家有床/可睡，避免把重生点记成无效坐标；
- outpost 过期后转 archived/custom，不直接删除。

## 6. 与现有代码的关系

```text
places.kind 保留
新增 role / unique / isTest / parent / expireAt
#homePos() 改为按 role=home 解析，冲突 fail-closed
test-base 从生产候选排除
```

## 7. 验收

```text
同 dimension 只有 1 条 active role=home
1 个 base 带 radius/bbox
1 个 outpost 带 parent + expireAt
回家目标 = 唯一 home
重叠 base 被拒并有 reason
outpost 过期不再被引用
生产 run 不使用 isTest 基地
```

判负：

```text
≥2 条 active role=home 且决策依赖遍历顺序
outpost 过期仍被当目标
生产 run 使用 isTest 基地
```
