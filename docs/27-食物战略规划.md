# 27. 食物战略规划（多来源）

> 状态：**规划，不实现**。当前实机 HP 1 / 饥饿 0 / 食物 0，先人工喂一次脱离危险，再按本文推进。

## 1. 问题拆成三层目标

| 目标 | 场景 | 验收 |
|---|---|---|
| **急救** | 饥饿 ≤ 2 或 HP 很低 | 先吃任意安全食物，脱离饥饿/低血 |
| **恢复** | 饥饿 3~8 | 吃到 16~18，恢复自然回血 |
| **储备** | 平时/白天 | 家里箱子有 ≥N 个熟食，避免下次断粮 |

不能用一个“找食物”包同时做三件事，否则要么太急、要么太远。

## 2. 多食物来源清单

| 来源 | 食物 | 优点 | 风险/成本 | 阶段 |
|---|---|---|---|---|
| 背包现成 | 熟肉/面包/苹果等 | 最快 | 数量有限 | P1 |
| 家里/已知箱子 | 存粮 | 安全、便宜 | 需要箱子位置 | P1 |
| 主人投放/身边 | 主人给的食物 | 最安全 | 依赖主人 | P1 |
| 熔炉/营火烹饪 | 生肉→熟肉、土豆→烤土豆 | 提升营养、安全 | 要炉+燃料 | P1 |
| 猎动物 | 牛/猪/羊/鸡/兔 | 营养高 | 要武器、找动物 | P1 |
| 钓鱼 | 鳕鱼/鲑鱼 | 可再生、风险较低 | 要钓竿（木棍+线）、水域 | P2 |
| 村庄 | 干草垛→面包、作物、箱子 | 一次解决很多 | 路途远、可能有怪 | P2 |
| 作物/浆果 | 小麦/胡萝卜/土豆/甜浆果 | 稳定、可种植 | 要找到/种植 | P2 |
| 树叶苹果 | 苹果 | 无需工具 | 掉率低、不可靠 | P3 |
| 腐肉/蜘蛛眼 | 应急 | 随处可得 | 饥饿/中毒效果，尽量不用 | 仅急救 |
| 农场/牧场 | 长期 | 稳定 | L4 工程 | P3/P4 |

## 3. 分层设计

### 3.1 需求层

```text
need: food_low
  触发：饥饿 ≤ 8，或 HP 低且饥饿 < 18
  优先级：饥饿 ≤2 → 90；3~5 → 80；6~8 → 60；HP<40 再 +10
  done：饥饿 ≥ 16（或吃到安全食物后转恢复）

need: food_stock_low
  触发：白天/在家、箱子熟食 < N
  优先级：30~40（效用型，低）
  done：箱子熟食 ≥ N
```

### 3.2 协调器 L3：`secure_food`

按“成本从低到高 + 当前可用”选一个来源，**一次只做一个子战略**，完成后再评估：

```
1. 背包里有可直接吃的 → eat_to_recover
2. 已知箱子有食物 → fetch_food_from_chest → eat
3. 主人在附近/主人投喂 → collect_items → eat
4. 有生食 + 炉/燃料 → cook_food → eat
5. 附近有动物 + 有武器 → hunt_animal → cook → eat
6. 附近有水域 + 有钓竿/线 → fish_food → cook → eat
7. 附近有作物/浆果 → harvest_crops → eat
8. 附近有村庄 → village_food（白天、安全）
9. 应急：腐肉（仅饥饿≤2 且无其他来源）
10. 都不行 → 上报主人 / 回主人身边 / 等天亮
```

### 3.3 子战略（L2）

| 战略 | 行为 | 依赖 |
|---|---|---|
| `eat_to_recover` | 吃背包食物到目标饥饿 | 已有（需扩展食物表） |
| `fetch_food_from_chest` | 找箱子→scan→取食物 | `scan_container/fetch_batch` |
| `cook_food` | 放/开炉→烧生食→取熟食 | 熔炉+燃料（复用 `make_charcoal`） |
| `hunt_animal` | 找动物→攻击→捡掉落→烹饪 | 武器、`find_entity`、`attack_target` |
| `fish_food` | 做钓竿→钓鱼→烹饪 | 线（蜘蛛/箱子）、水域 |
| `harvest_crops` | 找作物/浆果→收→吃/存 | `harvest_crop` 战术 |
| `village_food` | 去村庄→干草垛/作物/箱子→面包 | 村庄定位、路线安全 |
| `emergency_rotten_flesh` | 吃腐肉 | 仅急救、记录副作用 |
| `stockpile_food` | 猎/钓/收 + 烹饪 + 存箱 | 箱子和炉 |

## 4. 来源选择：不要固定顺序，用效用分数

固定阶梯只是默认；实际按分数选：

```
score = 营养期望 × 数量
      + 安全加成（在家/白天/主人附近）
      - 风险（敌对/夜间/远）
      - 时间/路程成本
      - 工具缺口惩罚
```

示例：

- 家里箱子有 8 个熟牛肉 → 分数最高；
- 附近 10 格有牛、有剑 → 猎杀分数高；
- 夜里、离家 80 格有村庄 → 分数极低（不去）；
- 只有腐肉、饥饿 0 → 应急分数才上来。

## 5. 昼夜规则

- **白天**：允许打猎、钓鱼、去村庄、采集；
- **黄昏**：停止远行，优先回家/取箱子/烹饪；
- **夜晚**：只允许“背包吃、箱子吃、基地内烹饪”；不打猎、不钓鱼、不去村庄；
- **低血急救**：夜里也允许“主人身边/箱子/背包”的短路径，不出去远征。

## 8. 验收指标

- 饥饿 ≤2 时，10 分钟内吃到东西的比例；
- 因饥饿导致无法回血/死亡次数；
- 食物来源成功率（背包/箱子/烹饪/猎杀/钓鱼/村庄）；
- 每晚/每天食物净消耗；
- “有食物但没吃/吃错”的次数；
- 箱子熟食储备是否达到目标。

## 9. 风险

- **腐肉依赖**：只能急救，不能当主食；
- **烹饪燃料**：没炉/没燃料时，猎杀生肉也只能应急；
- **夜间远征**：食物优先级不能压过安全需求；
- **来源误判**：动物/水域/村庄可能不存在，需要有限扫描 + TTL；
- **食物浪费**：先吃快坏的/低价值的，熟食留恢复；
- **主人依赖**：主人投喂是快路径，但不能作为唯一方案。

﻿## 11. 自给自足原则（2026-11-09 用户强调）

**项目终极目标：同伴自给自足，尽量不依赖主人干预。**

因此食物方案的取舍：

- “主人投喂/主人身边”只作为**最后兜底**，不是常规来源；
- 常规来源优先级：箱子存粮 → 烹饪 → 猎杀/钓鱼/采集 → 村庄；
- 必须逐步具备：自己做工具→自己获得燃料→自己烹饪→自己储备；
- 需求/战略失败时，优先生存/回家/再找来源，而不是先喊主人；
- 主人干预只用于：急救、卡死恢复、调试；不作为设计前提。
