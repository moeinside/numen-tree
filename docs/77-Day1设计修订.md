# 77. Day1 设计修订（点子王质询后）

> 行为/MC 合并稿 + 点子王质询后的 Lead 修订版。  
> 定稿前交项目经理审核。

## 1. 定性

Day1 是 **能力验收场景**，不是自主能力证明。

- 报告只能写“该夹具下可跑通”；
- 不能写“验证了自主生存/泛化”。

## 2. 入口

- A：有可见树 → 默认倾向采集；
- B：无可见树 → **一次有界探索**（≤90s / ≤2 跳），dusk 剩余 <40% 直接放弃；
- C：低血/夜/水/威胁 → 硬门/反射优先。

找不到树时 `log_unseen=unknown`，不写“没有”。

## 3. milestone（结果型）

- **M1 有木**：原木 ≥6（给 M2/M3 留余量；4 根会因桌+工具零余量而崩）。
- **M2 有工作台**：已放置且 L1 现场可交互。
- **M3 有可用工具**：至少一件木工具在包，且**绑定 attempt 的一次使用证据**：
  - 手持工具 + 动作前后 item/world 双观测；
  - 无法取得证据 → `tool_unused`，不伪装成“已使用”。
- **M4 夜间安全**：
  - **night_no_damage**：入夜后 HP 无下降、无死亡、无贴脸新增敌对；
  - **food_ok**：食物存量 ≥2 或饥饿 ≥14；
  - 火把路径**删除**（从零需熔炉/木炭，Day1 不保证）；
  - 封闭庇护可选，不默认要求。

**Day1 通过 = M1 + M2 + M3 + night_no_damage + food_ok。**

## 4. 木→石 / 斜坡挖

- 木→石：Day1 非必须，Day2 首个 milestone；
- **斜坡向下挖：Day1 砍掉**；
- 无裸岩：允许 M2/M3 未达成，标记 `material_unavailable`，不硬挖。

## 5. 失败分类

必须区分：

- `capability_fail`：有素材/机会但系统没做到；
- `material_unavailable`：世界没给树/动物/裸岩；
- `unknown`：观测失败/不确定。

Day1 报告不能把“无动物”匿名合并成“通过”；无食物通过必须单独统计。

## 6. 硬门

生命 > 脱困 > 饥饿 > 夜间暴露 > 资源 > 建造。

- 溺水/贴脸/低血：反射；
- 饥饿 <6：覆盖除反射外所有计划；
- HP<8 且饥饿<8：只允许进食/撤回/休息；
- HP<10：禁下水/下矿/战斗；
- 饥饿<14：提前食物准备；
- dusk 剩余 <40%：停止开新采集，转夜间安全。

## 7. 行为序列

- 黎明：观测 + A/B；
- 上午：M1→M2；
- 午后：M3 + 食物准备交替；
- 下午中段：食物优先；
- dusk：收工转 M4；
- 夜：光照内守夜/整理，禁止远行。

食物主路线：打猎（生肉可吃，生鸡肉除外）；箱子/村庄不做 Day1 保底。
无动物：记 `material_unavailable`，接受 Day1 不通过，不藏进报告。

## 8. 架构约束（总控）

不让步：三态、postcheck、plan≠milestone、L0/L1 动作前置、失败三分、单槽。

留桩不实现：

- WorldHints（L2，只 explore/verify，P0 off）；
- 结果型 GoalProfile/依赖/回退；
- SpatialMemory 查询面；
- CompanionKnowledge 溯源；
- 观察预算/注意、状态快照/恢复、决策理由记录；
- 多同伴 sender/version。

不能写死：坐标、树种/biome、固定第一步/路径、食物来源、半径阈值、单 biome。
可以固定 SOP：木→板→台→木工具顺序、夜间三选一（删火把后为食物/庇护）、硬门、失败降级。

## 9. 接口

Fact：`log_visible/stone_visible/animal_visible/table_reachable/in_water/on_ground/food_stock/night_safe/stuck/held_tool/item_delta`，每条 source/observedAt/ttl。

动作：`criticalFacts` + `expectedPredicate` + `attemptId`。

## 10. 明确不做

- WorldHints 运行时；
- 多同伴；
- SpatialMemory；
- 新战术/战略包（from_zero 除外）；
- 石工具/熔炉/床/3×3 木屋；
- 斜坡挖/竖井；
- 写死 S0–S7；
- 调阈值过验收；
- 扩感知。

## 11. 一句话

> **Day1 只证明“该夹具下能从 0 走到第一夜安全”；木头给足余量、工具使用有 attempt 证据、食物和安全分开判、无素材明确记为 material_unavailable。**
