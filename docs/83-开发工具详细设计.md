# 83. 开发工具详细设计：Pilot + Lock/Unlock + Cheat

> 2026-11-10。基于 docs/82 共识。  
> 目标：LLM 参考运行、实时观测、独占 numen MCP、可解锁、dev 期作弊；不污染 Track A。

## 1. 端口/所有权

| 端口 | 服务 | 谁持有 |
|---|---|---|
| 8765 | numen MCP | 树 daemon 或 pilot（**互斥**） |
| 8767 | 树 MCP | 树 daemon |
| 8768 | numenlockfix 补丁 | 只读/清锁 |
| 8769 | 触手 | 只读观测 |

规则：

- pilot **只连 8765**，绝不连 8767；
- 树活着时 pilot 不允许启动；
- 同一时间只允许一个 pilot；
- 以**全局 lease 文件 + OS 文件锁 + heartbeat** 保证。

## 2. 状态机

```text
IDLE
 → ACQUIRING（抢 lease）
 → HANDOFF（让树优雅退出）
 → CLEAR_LOCKS（清僵尸锁）
 → FIXTURE（可选作弊布置）
 → RUNNING（LLM pilot）
 → SETTLING（停手/等收敛）
 → RELEASING（解锁/可选重启树）
 → IDLE
```

任何一步失败 → `ABORTED`，保留日志，不自动删同伴。

## 3. Lock / Unlock

### acquire

1. 原子创建 `run/.pilot-lock`（O_EXCL / OS lock）；
2. 读 owner/pid/heartbeat；过期且 PID 死 → `--recover-stale`；
3. 检查 8767：若树在，执行：
   ```
   node src/cli.mjs control --op exit
   ```
   等待 8767 释放（≤240s）；**不 taskkill**；
4. 检查 8765：`list_companions` 必须可通；
5. 清僵尸锁：
   ```
   node src/cli.mjs lock --all
   ```
   必要时 `--reset-brain`；
6. 写 lease：owner、pid、runId、expiresAt、treeWasRunning；
7. heartbeat 每 5s。

### release

1. pilot 停止接新动作；
2. 等在途 Lua 收敛（timeout）；
3. 调 `numen.task.stop` / `get_events` 确认无后台任务；
4. `node src/cli.mjs lock --all`（或仅 companion）；
5. 删 lease；
6. `--restore-tree` 时才重启 `node src/daemon.mjs`；
7. 记录 `unlock.ok/blocked`。

### 强制恢复

- 只有 PID 已死、heartbeat 过期、或人工 `--force` 才允许；
- `--force` 前必须 `lock --all`，并写审计；
- 永不 `taskkill` 树进程；永不删同伴作为清锁手段（除非最后手段并记录）。

## 4. numen MCP 作弊能力（已查实）

### 现有

`tools/list` 只有：

```
list_companions / create_companion / delete_companion
get_events / say / lua / skill / todo / memory
```

**没有通用 `command` 工具。**

唯一接近作弊码的是 Lua：

```lua
numen.creative.give(item, {count = n})
```

帮助原文：

> Creative mode only: conjuring items, like the creative menu.

它只能：

- 同伴处于创造模式时，凭空给物品；
- 不能 `tp/time/setblock/summon/effect`；
- 世界未开作弊/同伴非创造时失败。

### 结论

- 你看到的“numen MCP 作弊码”大概率就是 `numen.creative.give`；
- 当时失败 = 同伴不是创造模式或世界 cheats 关闭；
- **不要**试图在 tool 里绕过；明确报 `cheats_disabled`。

## 5. 开作弊的路径

### A. 测试世界创建时开

- 新建世界时 `Allow Cheats: ON`；
- 同伴用命令/桥接设为创造；
- 这是最干净的方式。

### B. 已有单机世界

- `Open to LAN` → `Allow Cheats: ON`（临时）；
- 或离线备份后改 `level.dat allowCommands`（不推荐自动做）；
- 然后通过命令通道 `/gamemode creative`。

### C. 只有 numen MCP

- 无法自己开 cheats；
- 只能 `creative.give`（前提已满足）；
- 其他作弊需 dev 命令桥/RCON，另开 gate。

## 6. Cheat 设计

### provider

```text
CheatProvider
├ NoneProvider（默认）
├ CreativeGiveProvider（numen.creative.give）
├ MockProvider（测试）
└ CommandProvider（未来：dev-only mod HTTP / RCON）
```

### 规则

- 只在 **FIXTURE** 阶段可用；
- RUNNING 阶段零 cheat；
- 每次操作写 `events.cheat.jsonl`，带 runId/reason；
- 不写 Facts/记忆/学习；
- 报告标 `mode=dev-cheat`；
- `CreativeGiveProvider` 启动时验证：
  - 同伴在线；
  - `creative.give` 可用；
  - 失败 → `cheats_disabled`，不重试绕过。

### 允许（fixture）

- `give_wood_kit`
- `give_food`
- `give_torch`
- `set_time`（仅 CommandProvider）
- `tp_safe`（仅 CommandProvider）
- `spawn_animal`（仅 CommandProvider）

### 禁止

- `effect`、`gamerule`、`difficulty`、`kill @e`、`clear`、`fill/clone`、`data merge`；
- 改同伴决策/记忆；
- RUNNING 中给资源/传送/回血；
- scanWorld 进运行时。

## 7. 运行生命周期

```text
preflight
  → acquire lease
  → handoff tree
  → clear locks
  → fixture（可选）
  → pilot loop
      - LLM tool call
      - external JSONL
      - live observer
      - step/time/cost caps
      - human approve (per N steps / irreversible)
  → settle
  → release
  → report
```

## 8. 实时观测台

只读：

- 位置/HP/饥饿/手持；
- 当前动作/工具调用/结果；
- postcheck/unknown/failure；
- 时间线；
- 人工批准按钮/kill switch。

数据来源：

- `get_events`（不吃 Lua 槽，实测）；
- `list_companions`；
- 树侧 status（树停后不可用）；
- 外部 JSONL。

不做：

- scanWorld；
- 写 Facts；
- 直接驱动树。

## 11. 失败处理

| 情况 | 处理 |
|---|---|
| 树占 8767 | 等 `control --op exit`，超时 abort |
| Lua 槽被占 | `lock --all`；仍占则 abort |
| MCP timeout | 重试上限；不 taskkill |
| 另一 pilot 持锁 | 拒绝，显示 owner |
| lease 过期 PID 死 | `--recover-stale` |
| cheats 关闭 | 报 `cheats_disabled`，不绕过 |
| 停机失败 | 保留锁/日志，人工介入 |

## 12. 最小 MVP

1. lock/unlock + preflight；
2. LLM MCP 单步循环；
3. raw JSONL + 只读观测台；
4. 人工批准 + caps + kill；
5. settle/unlock；
6. CreativeGiveProvider（可选）。

暂不做：

- CommandProvider/RCON；
- scanWorld；
- segmenter/review pack；
- 自动长跑；
- 自动恢复树。

## 13. 一句话

> **pilot 是独占 numen MCP 的参考驾驶员：先租锁、让树优雅退出、清僵尸锁，再跑；跑完 settle、清锁、解锁；作弊只允许在 fixture 阶段用 `creative.give`，RUNNING 阶段零作弊。**
