# 115. 夜间长链与注意力共识

> 2026-11-11。行为学家 + MC 专家 + 点子王，两轮对抗后共识。  
> 触发：玩家体感同伴 ADHD、几乎原地发愣；`secure_food` 夜里卡住，长链仍被排入夜间。  
> 说明：此前 `dark → inventory/near chest ≤16 → no_food_night` 只是局部补丁，不作为最终方案。

## 1. 根因排序

```text
1. goal 生成期缺“字段级 preflight / 时间窗”
2. 夜间没有显式基线行为 → 无候选 = 发愣
3. 承诺/切换成本不足 → ADHD 观感
4. action gate / 派发层僵尸态只是次生缺陷
```

关键结论：

```text
长链是在生成时排进夜间的
后层只能打断，不能“排不进去”
```

## 2. 共识方案

### 2.1 字段级 preflight，门在 goal 生成之前

对每条长链分别检查：

```text
场（是否需要离家/外出）
暴露（hostileDistance / hp / 夜间视野）
剩余时间窗（是否够完成第一步/整段）
工具/材料前置
```

任一不满足：

```text
不生成目标
记 preflight_denied / night_denied
不进 capability_fail 分母
```

不是“先生成再挂起”，也不是“挂起当合法状态”。

### 2.2 夜间 method table

每个 method 标：

```text
window: day | night | any
exposure: low | high
```

夜间只暴露低暴露、短链方法：

```text
背包进食
近处已登记容器（≤16）
就地封口避难
守夜/整理/盘点
短距移动
```

夜间默认不生成：

```text
外出觅食/探索
远程容器
狩猎
跨区寻路
首次采集/大件建造
```

### 2.3 夜间基线行为（必须有）

无长链候选时，默认 current 落到：

```text
eat_if_possible
→ 侧向 1×2 洞封口
→ 守夜/整理/盘点（带 next-check）
```

每一步必须带：

```text
reason
解除条件（天亮 / hostile=0 / 库存确认）
上限
```

不能空 plan 静默。

### 2.4 已有长链遇到入夜

```text
挂起并保留 milestone
→ 转基线行为
→ 不判失败
→ 次日清晨恢复
```

同链同窗口重排次数设上限；超限降级短任务或显式 abandon。

### 2.5 承诺

```text
入夜后不开新段
当前段完成/失败/超时才可切
硬安全除外
```

## 3. 各方让步

- 行为学家：承认“无默认行为/空 plan”是独立缺陷，不只是注意力二次症状。
- MC：放弃“排程层 + 派发层双层强制拦截”，只保留派发层观测/断言。
- 点子王：承认“先不生成”优先于“降级方法表”，method table 是第二层。

## 4. 最小验收

夜间夹具：

```text
入夜、饥饿≤6、背包0食物、16格内无容器无动物
```

判负：

```text
1. 夜间生成/派发离家长链（forage/seek_food/explore/go_to）≥1 次
2. 任意 5–10s 窗口无动作且 trace 无 reason
3. 夜间找不到 preflight_denied/night_denied 却发生了外出
```

通过：

```text
出现 no_food_night / 避难 / 守夜，带 reason
次日清晨恢复长链且 milestone 未丢
```

## 5. 实施顺序

1. method table + 字段级 preflight，放在 goal 生成前；
2. 夜间基线行为；
3. 已有长链入夜挂起 + milestone；
4. 同链同窗重排上限；
5. 最后才调 attention 参数。

## 6. 红线（仅原则）

```text
降级必须留证；“够不到”不得计成 capability_fail
禁止悄悄缩小搜索半径当修复
```
