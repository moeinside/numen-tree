# 79. 开发工具提案：LLM Pilot + Dev Cheat Bridge

> 2026-11-10。一个开发工具，不是顾问智能体。  
> 目的：LLM 直连 numen 跑一天 + 开发期作弊旁路，为未来功能留捷径。  
> 本文待顾问团质询。

## 1. 工具结构

```text
LLM Pilot Harness
├ pilot：LLM 直连 numen MCP 操作
├ recorder：raw JSONL 外部落盘
├ segmenter/summarizer：分段摘要，防上下文爆炸
├ stop controller：到点优雅断联/settle/lockfix
├ review pack：给圆桌的切片
└ dev CheatBridge（仅 --dev --allow-cheats）
   ├ RconCheatProvider（首选）
   ├ ModHttpCheatProvider（单机备选）
   └ MockCheatProvider（测试）
```

## 2. 作弊能力

允许：

- give / tp / time / weather / summon / setblock / fill / effect / xp / gamemode / difficulty / kill / clear；
- scanWorld（世界状态扫描）；
- snapshot/restore（场景回滚）。

禁止：

- 改同伴决策/记忆/内部状态；
- 把 cheat 结果写 CompanionFacts；
- 用 cheat 满足动作前置；
- 用 cheat run 作为 Day1/P0 验收；
- 生产世界/生产配置启用。

## 3. 隔离

- 双开关 `--dev --allow-cheats`，默认关；
- 测试世界/专用服；
- run 标记 `mode=dev-cheat`；
- cheat 事件单独 channel；
- review 默认过滤；
- 开跑前备份、结束后 restore/清理。
