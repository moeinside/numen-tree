# 34. 预期目标与工作先后指南

> 2026-11-09 用户确认。北极星：给 numen 的具身身体装一个**模拟脑**（不是解剖学大脑）。  
> 当前阶段：**先把“无 LLM 也能有限自主生存”的简单脑做出来**，再补记忆/学习/人格/社会认知。

## 1. 目标层级

### 北极星

给 numen 的具身身体装一个能自主生存、能被高层意图引导的模拟脑；  
numen 保留延髓反射与身体动作，项目只补少量神经（触手感知、lockfix 修锁）。

### 当前阶段目标（P0）

**无 LLM 干预下的有限自主生存闭环：**

```
需求 → 优先度仲裁 → 战略 profile → 战术 → 原子动作
```

要求：

- 空手能自己补工具；
- 饥饿能自己找食物/恢复；
- 夜晚能回家/守家/准备；
- 卡住/死亡后能恢复；
- 任务不打架、不无限重开、不空转。

### 后续阶段（P1+）

1. 感知整合/注意力/显著性；
2. 工作记忆 + 地点/情景记忆（海马）；
3. 结果反馈/策略统计（最简学习）；
4. 自我模型/置信度/失败归因；
5. 内驱力/偏好/人格（右脑层）；
6. 社会认知/对话；
7. 黑板/长期项目（分基地、农场、多同伴）。

## 2. 工作先后

### 第一步：收尾钓鱼链

- 触手 v0.3（水域/冰面）已安装；
- `fish_once` / `fish_food` 已实现；
- 实机验证 `tree_world.water` 与 `tree_task "钓鱼"`；
- 有钓竿/水/冰面时跑通。

### 第二步：优先度 MVP + 意图归并（当前重点）

- 统一候选接口；
- 承诺、切换成本、迟滞、硬抢占；
- 同一意图只允许一个 owner：
  - `gear_recovery`
  - `food_security`
  - `night_safety`
  - `stuck_escape`
  - `materials_storage`
- 计划步骤纳入当前意图，不再独立抢；
- 可观测：当前候选、分数、承诺、切换原因。

### 第三步：战略包按 profile 补齐生存闭环

- `gear_recovery`：空手→采集→工作台→工具/武器→换手；
- `food_security`：背包/箱子/猎杀/钓鱼/烹饪/急救；
- `night_safety`：白天准备、夜里守家/睡觉；
- `stuck_escape`：卡住/无路/危险恢复；
- `materials_storage`：存料/取料/回收。

每个 profile 要有：前置、节点、验收、局部 fallback、失败分类、checkpoint。

### 第四步：无 LLM 验收

- 无 LLM 指令下活过 N 个昼夜；
- 空手能补工具；
- 饥饿能找食物/恢复；
- 夜晚能回家/守家；
- 卡住/死亡能恢复；
- 不出现“多战略各做 30%”的抖动。

### 第五步：后续脑区

感知整合、记忆、学习、自我模型、内驱力/人格、社会认知、黑板。

## 3. 架构边界

1. 不重造身体：动作/寻路/战斗/合成继续用 numen；
2. 延髓让路：numen 反射最高优先；
3. 神经要小：触手只感知，lockfix 只维修；
4. 脑归树：需求/优先级/战略/战术/记忆/恢复归树；
5. LLM 是皮层顾问，不参与实时反射；
6. 优先度系统负责“选与切”，战略 profile 负责“分解与局部自救”，执行监督器负责“节点评估与 rescue 请求”。

## 4. 判断标准

短期看：

- 无 LLM 生存闭环是否成立；
- 切换频率是否下降；
- 任务完成率是否上升；
- 空手/饿死/夜死/卡死是否减少。

中期看：

- 是否能记住地点/失败；
- 是否能从结果调整策略；
- 是否能表达“为什么”；
- 是否有多同伴/项目能力。

## 5. 不在当前范围

- 完整情绪/意识/主观体验；
- 大规模农业/建造/探索；
- 多同伴共享黑板；
- 复杂 LLM 与语义匹配联动；
- 压力池/志向层/职业参数（等行为稳定后再做）。
