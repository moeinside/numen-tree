# 124. V3：议程 + 焦点 + 再入线索

> 2026-11-11。点子王 × 行为学家，在 V2 排班方案之外提出的更优解。  
> 不是时刻表，不是分层栈；时间只做约束，不做格子。

## 1. 结论

```text
V3 优于 V2。
V2 的段表保留，但只做环境门控，不做排课。
P0 不动。
```

## 2. 结构

```text
锚点 deadline
议程（3–5 条结果承诺）
焦点（同一时刻只一个）
再入线索（地点/物品/玩家）
机会窗口（原子边界插入）
空焦点基线
```

### 锚点 deadline

```text
天黑前回家
进食窗
守夜
```

只有“最晚开始/最晚完成”，没有时间段。

### 议程

```text
obligation {
  predicate,       结果谓词
  deadline,        最晚时间
  must|soft,
  evidence,
  fallback,
  lastProgress
}
```

上限 ≤7，`must` 必须有 deadline。

### 焦点

```text
同一时刻只有一个当前焦点
段级承诺
只在原子边界切换
```

### 再入线索

```text
地点、物品、玩家提示
→ “该回去做那件事了”
```

替代 A1 全天重排。

### 机会窗口

```text
低风险、就地、能换取信息
只在原子边界插入
完成后回焦点
```

### 空焦点基线

```text
观察 / 整理 / 社交 / 恢复
```

没有到期义务时也有合法行为。

## 3. 选择规则

```text
每拍只做一次 O(n) 比较：
最早到期义务 vs 当前最便宜机会
```

没有班次、没有跳班、没有返班。

## 4. 失败处理

```text
同谓词换方法 ≤2
→ 仍失败 → 记 missed
→ 放弃/换议程项
```

不做“跳必须班次”，因为不存在班次。

## 5. 为什么比 V2 好

```text
没有时间段 → 不易课表化
没有班次跳转 → 少一层机制
议程是持久记忆 → A1 不会失忆
再入线索替代全天重排
机会窗口提供弹性
```

V2 的段表仍保留，但只用于：

```text
夜晚/黄昏暴露门控
安全窗口
```

## 6. 风险

```text
议程变成 todo 清单
deadline 估不准
焦点切换频繁
机会窗口变成乱逛借口
再入线索缺失导致忘记
```

## 7. 判负

```text
存在无 deadline 的 must 义务
同一义务换方法 >2
放弃未记 missed
同一 30s 窗口“义务↔机会”切换 >2
没有 deadline/事件/基线耗尽，焦点按时钟边界自动切换 >0
错过 must 义务但 Day1 仍判通过
```

## 8. 排期

```text
P0：不动
P1：薄骨架（3–5 议程 + deadline + 单焦点）
P2：机会窗口、再入线索、完整结算
```

## 9. 一句话

```text
人不是按时刻表活着，
而是“少量没还的债 + 一个当前焦点 + 环境提醒”。
```
