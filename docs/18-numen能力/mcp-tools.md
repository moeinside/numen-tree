# MCP 工具层（numen MCP）

> 来源：`tools/numen-cap/build.mjs --mcp` 抓取（`docs/18-data/mcp-tools.json` 为机器可读原文）。
> 这一层**不占 Lua 槽**（除 `lua` 本身），是树与 numen 之间的 9 个入口。

| 工具 | 作用 | 关键点 / 树里怎么用 |
|---|---|---|
| `list_companions` | 列出主人的同伴（name + id） | 树启动/发现同伴时用；**先查它再驱动** |
| `create_companion` | 召唤新同伴（名字 3~16 字符） | 重建 SOP 用（树不直接调，走外部/控制口） |
| `delete_companion` | 永久解散同伴（掉背包/装备） | 重建 SOP 用；**不可逆** |
| `get_events` | 长轮询同伴收件箱：主人说话 `<query>`、世界事件 `<event>`；短轮询约 2 秒一次 | **唯一不占 Lua 槽的并行通道**；肾上腺素/报警的候选来源；事件读后即消耗 |
| `say` | 同伴说话（聊天/气泡/语音） | 树上报/台词用 |
| `lua` | 跑一段 Lua 5.2 程序，返回一个回执；**所有游戏内动作都走它** | 唯一执行入口；每同伴同时只能跑一个程序（唯一槽）；长程序不可取消（除非外部 cutOff） |
| `skill` | 加载一个"技能说明书"（工作流文本） | 早期给 LLM 直控用的；**树路线可以不用**（树自己拆技能），但可当知识来源 |
| `todo` | 写"待办清单"（多阶段计划的勾选板），每次覆盖整份 | LLM 直控模式用；树模式可忽略（树的计划/上报另有结构） |
| `memory` | 跨会话笔记（remember/recall/forget） | LLM 侧记忆；树有 places/worldmem，各自独立 |

## 对树设计的意义

- **动作唯一入口 = `lua`**：战术包/原子动作最终都编译成一次 `lua` 调用；
- **并行感知只能走 `get_events`**：它不占槽，但只报"发生了什么"，不能主动扫现场；
- `create/delete_companion` 是**重建 SOP** 的底层，树不自动用（防止丢背包）；
- `skill`/`todo`/`memory` 属于"LLM 直控时代"的工具，树路线不依赖，但保留兼容。
