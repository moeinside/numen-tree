# 41. 里程碑评估：三线调度（本能/压力/注意）v0

> 2026-11-09 里程碑阶段。目标：让行为“看起来像有个脑子在决策”。

## 1. 已落地

### 三线状态

- **本能线** `src/instinct.mjs`：溺水/低血/贴脸威胁 → 硬信号；只输出，不直接执行。
- **压力线** `src/drives.mjs`：hunger / fatigue / safety / resource 压力池；按秒累积，满足清零 + 饱腹不应期。
- **注意线** `src/attention.mjs`：外源（威胁/疼痛）+ 内源（压力偏向）+ 当前意图聚焦；输出 salience 与强捕获信号。
- 三线状态进入 `tree_status detail`：`drives / attention / instinct`。

### 调度器

- 需求 → 单意图候选；
- 候选分 = 需求分 + 压力加成 + 注意加成 + 本能加成；
- 同一时间只允许一个需求目标；
- 切换成本/承诺；
- 自动计划必须过意图闸门；
- 夜间不反复排“出去补装备”；
- 运行中 plan 也显示在 `intentState`。

### 战略包结构

- 按领域拆分：craft/food/fuel/night/safety/storage/escape；
- `fish_food` 补了“烤失败→生吃、存储失败不判失败”；
- 玩家干预短报 `intervention_needed`；
- 契约：Facts / Profile / Candidate；战略桥 `profiles.mjs`。

## 3. 实机观察（约 2 分钟）

典型序列：

```
feed/eat 成功
→ bootstrap_kit（补装备）
→ safety_hold 完成
→ craft_tools 开始
```

- 不再出现多个 need 同时排队；
- 吃完后进入补装备，而不是立刻又找食物；
- 安全点候选能插队并完成；
- 夜晚不再每秒轮询装备。

## 4. 当前不足

1. **压力参数未标定**：增长/衰减速度是拍的，需要长时间观察；
2. **断点仍是目标级**：计划内部动作边界还没做统一抢占；
3. **没有 profile 执行层**：战略表只有数据/模块，没有 milestone 状态机；
4. **没有长期目标**：铁器时代/基地建设未接；
5. **没有习惯/学习/情绪**：人格层未做；
6. **资源贫瘠时仍会空转**：调度不能凭空生成食物/矿；
7. **目标回推（向上延展）待做**。

## 5. 评估

**“看起来像有脑子”**：部分成立。

- 有单一意图、有优先级、有承诺；
- 有压力/注意/本能三层状态；
- 有安全插队和计划闸门；
- 行为序列开始连贯。

但还不是“有人类行为逻辑”：

- 不会预判很久以后的需求；
- 不会从失败中学习；
- 没有长期志向；
- 压力参数会显得机械；
- 复杂环境仍会卡住/空转。

## 6. 下一步优先级

1. 压力参数实测标定 + 断点切换；
2. `fish_supply` / `tool_recovery` profile；
3. profile milestone 状态机（铁器时代）；
4. 目标回推（docs/40）；
5. 记忆/学习/人格后置。

## 7. 一句话

> 现在从“需求-应答队列”升级成了“三线状态 + 单意图 + 承诺 + 闸门”的调度器；行为连贯性明显提升，但离完整人类行为还缺 profile、预测、学习和长期目标。
