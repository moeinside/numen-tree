# 144. S0 字段评审：MC 结论

> 2026-11-12。MC 专家窄评审。  
> 结论：**有条件冻结**，不是直接冻结。

## 1. 不能当事实写的字段

```text
死亡 cause / killer / inventorySummary
  numen 无死亡原因/快照
  触手 v0.3 无 death 事件
  只有 groundtruth 的 LivingDeathEvent 能给
  → 分生产子集 / 夹具子集

xpLost
  numen 无 xp
  → 不加

三类时间占比 100%
  动作可跨域（挖石=生存+建造）
  分类唯一性不成立
  → 只能做派生指标，标 estimated

consentState=granted（自动）
  numen 同意是每动作现场判定
  持久 granted 会出现“账本说可以、执行说不行”
  → 改 policy_pre_authorized，允许 denied 回写

predicate
  必须带 predicateSource ∈ {L0,L1}
  否则变成隐式全知
```

## 2. 必须补的字段

### 承诺

```text
basis { snapshotSeq, gameTick }
ttl
supersededBy
retryBudget
deadlineWindow {
  windowType: day|dusk|night|absolute,
  remainingSec
}
```

### consent

```text
consentScope: per_action|per_region|per_session
consentCheckedAt
consentDeniedReason:
  owner_absent
  owner_placed_block
  region
  owner_offline
```

### 方法前置（阻塞项）

```text
preconditions[]
requiredToolTier
stationRef
requiredDimension
needsLoadedChunk
```

没有这些，`allowedMethods` 契约直接失效。

### 死亡

```text
生产子集：
  eventSeq, gameTick, pos, dimension, lastCommitmentId

夹具子集（source=groundtruth）：
  cause, killer, inventorySummary
```

### 事件通用

```text
source ∈ {numen, tentacle, groundtruth}
stale
```

## 3. consent 修正

```text
auto ≠ granted
auto = policy_pre_authorized

实际执行仍由 numen 现场裁决
refused → 回写 consentState=denied

玩家建筑/玩家放置方块区域：
  auto = pending 或 none
  不能 granted

external = pending 保留
```

## 4. 三类时间

```text
不能当运行时字段
只记 actionCategory × duration 的去向账
占比是报表派生值
标 estimated: true
不进运行时决策
```

## 5. 冻结条件

```text
1. 死亡事件拆生产/夹具两档
2. consent 加 scope/checkedAt/deniedReason；
   auto 改 policy_pre_authorized，允许 denied 回写
3. 承诺补 basis/ttl/supersededBy/retryBudget；
   deadlineWindow 加 windowType/remainingSec
4. 方法库补 preconditions/requiredToolTier/stationRef
   ——阻塞项
5. 三类时间占比降级为派生指标
```

## 6. 一句话

```text
字段主体可用，
但死亡因果/背包、consent、predicate 依据、三类时间占比
不能写成事实；
其中 preconditions 缺失会让 allowedMethods 契约直接失效。
```
