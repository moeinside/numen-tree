## 1. 背景

- 旧 Day1 失败：avgHP5、饥饿4、water_stuck/no_food/craft_failed；
- 已确认断点：结果型 milestone、前置回补、未知下入口、食物/低血硬门、候选可达性；
- 作弊扫描不进入运行时；WorldHints 只做后续 L2 接口，P0 默认关闭；
- “无脑撸树”不是固定第一步，而是“未知下低风险换信息的入口策略”。

## 2. Day1 目标

固定夹具新世界、0 资源、无 LLM、零干预、day0 黎明 → day2 清晨：

1. 自己发现树/资源并启动采集；
2. 原木 ≥4，木板/木棍；
3. 工作台 + 至少一件木工具并实际使用；
4. 入夜前至少一项保底：食物存量 / 火把或木炭 / 封闭庇护；
5. death=0；
6. 无 water_stuck/no_food/craft_failed 连续超时；
7. 无“动作 ok 但世界没变”；
8. 无 stale/unknown 当确定；
9. 可解释、可判负。

## 3. 设计必须回答

### 行为学家 + MC 专家

1. 入口策略：
   - 未知/空背包时，第一动作如何选？
   - “找树”是默认倾向、affordance、还是搜索子目标？
   - 看不到树时，探索/观察/等待如何切换？
2. 需求建立：
   - 从“世界状态”到“今天该做什么”的结果型 milestone 是什么？
   - 哪些是结果谓词，哪些只是手段？
3. 硬门与危机：
   - 饥饿/低血/夜间/水的硬门与优先级；
   - 防死亡螺旋。
4. Day1 行为序列：
   - 黎明→白天→dusk→夜的具体行为切片；
   - 食物保底选哪条（打猎/箱/村庄/其他）；
   - 木→石升级是否 Day1 必须。
5. 失败路径：
   - 没树/没动物/没裸岩/背包满/槽被占/入水；
   - 观察失败/未知如何降级。
6. 与架构接口：
   - 需要哪些 Fact/谓词/目标/观察接口；
   - 不写实现。
