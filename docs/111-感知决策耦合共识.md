# 111. 感知-决策耦合共识

> 2026-11-11。`idea-king` + `mc-expert` 两轮对抗后共识。  
> 触发：开放场同伴跑出 16 格，怪留在原地，行为看似“感知/决策脱节”；围栏后抖动从 25 降到 2。

## 1. 不采用的方案

**不采用“每 tick 单一 worldSnapshot + 单一时间戳”。**

原因：

- 单动作槽下无法每 tick 跑 scan；触手 1–2 Hz、2s latch、server timeout；
- 单一时间戳会把不同新鲜度的字段当成同时可信，是新的 fail-open；
- 快照会变成第二份事实源，和 FactStore 打架。

## 2. 共识方案

### 2.1 快照是 FactStore 的只读投影

```text
进快照的每个字段都带：
observedAt（game tick）
source（numen / tentacle / event）
radius
occluded
confidence
```

快照零写入；写入只经 FactStore。

### 2.2 字段级 TTL，不是整体 TTL

- 过期字段标 `stale`，不能参与抢占；
- 决策只消费“未过期且来源权威”的字段；
- 过期时允许 `wait/重观测`，不允许抢占。

### 2.3 刷新时机

不每 tick：

```text
动作派发前 preflight
动作结束后 postflight
1–2s 低频轮询
硬事件（reflex / 受伤 / 死亡）
```

新鲜度按 game tick 计，不按 wall clock。

### 2.4 字段权威

| 字段 | 权威 |
|---|---|
| hostile count / nearest / distance | numen `scan.entities("hostile")` |
| in_water / on_ground / terrain | 触手 |
| LOS / 遮挡 | 触手 + `scan.sight` 复核 |

冲突：

```text
较新且来源权威者胜
两者都新且矛盾 → unknown + 一次现场复核
禁止 last-write-wins
```

### 2.5 内圈/外圈

- 内圈决策：白天 = 配置半径，夜间 = min(半径, 16)（触手 Java 夜间硬砍 16）；
- 外圈 24–32：只做 awareness/方向/数量级，不触发抢占；
- 内圈要求 LOS；外圈不要求 LOS，所以只能提示。

### 2.6 反射边界

```text
instinct/reflex 不依赖快照
仍用 numen 硬信号
快照只服务树层决策
```

## 3. 最小验收（可判负）

1. **无怪不抢**：快照 hostiles=0 窗口内，没有任何 `outnumbered`/撤退类抢占；
2. **有怪必抢**：hostiles=3（双源一致）后 ≤1 个决策周期内出现 preempt；
3. **怪没不抢**：hostiles 回 0 后，不再出现同类抢占；
4. **过期禁令**：人为让快照超 TTL，抢占必须被禁止，只允许 wait/重观测；
5. **半径穿越**：同伴与怪 15→17→15，跨 16 时决策由 N→0 且抢占停止，回 15 后恢复；
6. 每次切换 trace 都必须指向同一条带 `observedAt/source/radius` 的证据。

任一不成立 = 感知与决策未耦合。
