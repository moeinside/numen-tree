# 35. 设计：安全点与基地巡逻

> 2026-11-09。目标：没有武器时优先回安全点；有武器时在基地周围巡逻。  
> 这是**优先度系统里的候选行为**，不是牵引绳/硬拉回。

## 1. 安全点判定

“更高/更低且有路径”只是候选，不能直接算安全。安全点用评分 + 校验：

### 硬性条件（不满足直接排除）

- 可站立：脚下 solid，脚/头 2 格空气；
- 不在水/冰面/岩浆里，不在其正上方；
- 不是悬崖边缘（相邻落差 > 3 格要扣分/排除）；
- 当前无近距离敌对（威胁距离 > 8~12 格）；
- 有路可达（选中后实际走一次；`no_path` 标记失效/冷却）。

### 评分项

| 项 | 偏好 |
|---|---|
| 离基地锚点距离 | 4~16 格最佳；太远/太近都扣分 |
| 相对高度 | 比基地高 1~4 格最佳；太高有坠落风险，太低/洞穴扣分 |
| 光照/封闭 | 光照 ≥8 或三面封闭加分 |
| 逃生路线 | 至少 2 个可走方向加分 |
| 视线/开阔 | 能看见来路加分；死角扣分 |
| 到基地路径长度 | 越短越好，但不要穿过水/悬崖 |
| 威胁距离 | 越远越好 |
| 记忆/已验证 | 上次验证成功、近期无失败加分 |

## 2. 安全点来源

1. **基地锚点**：地点簿里的 base/home，默认主安全点；
2. **Fallback 高点**：基地周围环采样，找“高 1~4 格、有路、无水、非悬崖”的点；
3. **已发现点**：散步/巡逻时验证过的位置，记入地点簿。

不预计算太多；先基地 + 最多 2 个 fallback，选中后实际验证路径。

## 3. 行为

### 无武器：`safety_hold`

- 触发：`!hasWeapon`，且（离家 > 安全半径 / 夜 / 有威胁 / HP 低）；
- 目标：最近的有效安全点；
- 到家后：待命/观察，不主动出远门；
- 途中遇敌：优先 retreat/绕行，不硬穿；
- 被安全中断：保留当前目标，回头继续。

### 有武器：`patrol_guard`

- 触发：`hasWeapon`，无紧急需求/计划，基地安全；
- 方式：围绕基地安全环（半径 6~12）走 2~3 个路点，不跑远；
- 遇敌：进入 guard/fight 或 retreat（按血量/数量）；
- HP 低/夜太黑/被围：回 `safety_hold`；
- 不阻止吃饭、补装备等更高优先级任务。

## 4. 和优先度系统/牵引绳的关系

- 两者都是 **候选 intent**，不是被动拉回；
- 无武器时 `safety_hold` 优先级高于普通工作；
- 有武器时 `patrol_guard` 是低优先级空闲行为；
- 保留危险中断（retreat/fight）；
- 不再使用固定距离牵引绳。

## 5. 验收

- 空手时不会主动远离基地；
- 夜里/被追时能回安全点，而不是原地硬扛；
- 有武器时巡逻不出安全半径，遇敌能回防；
- 安全点路径失败会标记并换点，不无限撞墙；
- 不影响吃饭/补装备等更高优先级任务。
