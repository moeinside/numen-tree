# 54. 感知契约三方审核共识

> 2026-11-10。架构师、行为学家、产品经理分别审核 docs/52 + docs/53。  
> 结论：**三方均有条件批准；感知契约方向正确，但必须补三条硬规则。**

## 1. 三方结论

| 角色 | 结论 | 核心条件 |
|---|---|---|
| 架构师 | 有条件批准 | 负证据规则、事实合并算子、观测预算/超时 |
| 行为学家 | 有条件批准 | unknown 决策表、防观察焦虑/停滞 |
| 产品经理 | 有条件批准 | P0 只验四条最小门槛 + 白名单 + 负样本校准 |

## 2. 必须补的三条硬规则

### A. 负证据规则（Negative Evidence）

“未观测到某物”不能直接变成“不存在”。只有满足：

- `partial=false`；
- 观测满足 radius/FOV/LOS；
- 观测时间在 TTL 内；

才允许降级为“很可能不存在”，否则必须是 `unknown`。

`unknown ≠ false` 不是口号，要写进 Facts 规则。

### B. 事实合并算子（Fact Merge）

同一个 key 可能同时有：

- 触手 sight（已 stale）；
- numen body；
- 容器交互/记忆。

规则：

- **单 key 单权威来源**，其余只作为候选；
- 冲突写 conflict 日志并降低 confidence；
- **禁止 last-write-wins**；
- stale 与 unknown 的比较规则固定；
- 双源冲突必须可被审计重放。

时间口径：

- 世界事实 TTL 用 **gameTick**；
- HTTP 超时/进程预算用 wall clock；
- 不允许双钟混用。

### C. Unknown 决策表（行为规则）

必须显式定义：

| unknown 类型 | 行为 |
|---|---|
| 安全类（低血/贴脸威胁） | 强制观测 |
| 动作前提、廉价现场检查可改变决策 | 观察 |
| 其余 | 保守默认动作（可达/可逆/避害） |
| 连续 K 次观察无信息增量 | 停止观察，决策或求助 |
| 观察预算耗尽/超时 | 转 unknown，求助/降级，不重试 |

防：

- 观察循环；
- 犹豫/原地停滞；
- 观察抢占执行造成新抖动；
- settle 后复观测拉长周期。

## 3. P0 感知验收（产品经理定）

P0 只验四条：

1. 使用 stale 事实执行动作的次数 = 0；
2. 把 unknown 当 false 的误判 = 0（审计注入“未观测即不存在”必须判负）；
3. 状态改变动作经 settle 后复观测覆盖率 = 100%；
4. 观察预算超限 = 0。

P0 只允许消费**白名单事实**：

- self / terrain / entity；
- water / landmark 只当候选，必须现场校验，**不进 P0 权威**。

P0 必须做感知负样本校准：

- 固定夹具预埋：隔墙水体、隔墙地标、视锥外实体各 ≥1；
- 触手 known 但审计 false 且被决策消费 → 判负；
- 统计 false-positive / false-negative。

## 4. 其他修正

- ObservationPlan 作为 Planner 前置子目标时，**不占方法回推 depth≤2 的预算**，只占独立观测预算。
- 观察延迟计入 A 的抖动/恢复延迟指标，不能算成回归。
- 观测超时/预算耗尽归因“信息缺失”，不算同策略失败。
- 安全类 unknown 才允许强制观察；其余不“观察一切”。

## 5. 最终架构 v1.2 补充

```
Observation {
  source, kind, observedAt(gameTick+wallTime),
  radius, fov, partial, confidence
}
Fact {
  key, value,
  status: known|unknown|stale,
  authoritySource,
  candidates[],
  observedAt, ttlGameTicks,
  confidence, evidenceSeq
}
```

- 单 key 单权威；
- unknown ≠ false；
- settle 后复观测；
- 观测预算独立；
- P0 白名单 + 四条门槛 + 负样本校准。

## 6. 一句话

> **感知可以后实现，但不能后验收；P0 只验“不拿未知当假、不用过期事实、动作后复观测、观察不超预算”。**
