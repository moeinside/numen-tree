# 114. 空间归属 / 回家决策共识

> 2026-11-11。行为学家 + MC 专家 + 点子王。  
> 现象：同伴出门跑很远，在远处活动；没有回家/回基地/就地避难/与主人汇合的行为选择。

## 1. 共识

- **不是硬圈住活动中心**；
- 也不新增一个“想家”的 needs 层；
- 正确做法：给候选选择增加**空间成本维度**，再加一个**紧急避难硬门**。

```text
候选不再只评“做什么”
还要评“在哪做、回家要多久、暴露多大”
```

## 2. 四类行为

| 行为 | 性质 | 触发 |
|---|---|---|
| 紧急就地避难 | **硬门**，不是候选 | 威胁贴身、低血、夜间无遮蔽 |
| 与主人汇合 | 候选/高优先 | 主人呼叫、主人受伤、主人是安全源、避难压力低 |
| 回家 | 候选/中优先 | 接近 dusk、离家超回程预算、携带易失资源、疲劳 |
| 回基地 | 与家同点则并入；不同点则夜间归家优先 | 储物/工作点 |

活动中心不是触发条件，而是**评分约束**，形成自然半径。

## 3. 防抖动

- 双阈值滞回：出门许可阈值 ≠ 强制归家阈值；
- 归家是**段级承诺**，除非硬安全打断；
- 回家后驻留冷却，避免“到家即出门”；
- 用“剩余日照够不够回程”而不是固定回家时刻；
- 每次 home↔out 切换必须有 reason 和新信息。

## 4. 机制缺口

MC 专家指出：

- 只有单点 base，没有活动中心/半径语义；
- place 没有 `shelter` 类型和 radius；
- owner 只有距离，没有坐标；但 `owner().pos` 可用，汇合只缺决策；
- `safetyHold` 只会去 home，不会就地避难；
- leash 只在空闲时生效，有任务时不拉回。

## 5. 可执行动作

```text
回家：move.to(home, arrive=near, range=3)
汇合：owner().pos + move.to(pos, range=2)
避难：侧向 1×2 挖洞 + 封口；失败靠墙角/火把
脱离：move.flee(mob, distance=20)
```

降级顺序：

```text
route.plan 不可达
→ 分段走
→ 方向性撤退
→ 就地避难
→ abandon + reason
```

`in_water` 或低血时禁止启动长距离回家。

## 6. 最小验收

夹具：

```text
距 base 40 格、白天、无敌对、家点已知、跑 60s
```

通过：

```text
出现 return_home/汇合/避难意图
60s 内 distance-to-home < 8
或明确 travel_failed → abandon + reason
```

判负：

```text
60s 内既无回家/汇合/避难意图，也无 abandon+reason
且仍在远离 home
```

加强版：

```text
回家路径横 3 格水或 2 格悬崖
要求分段/侧绕/避难
连续 3 次同参 travel_failed 判负
```

## 7. 实施顺序

1. place 增加 radius / shelter 类型；
2. owner 坐标进入决策；
3. 候选评分加 `distanceToHome / returnCost / exposure`；
4. shelter 硬门；
5. 回家段承诺 + 驻留冷却；
6. leash 降为最后兜底，不做主逻辑。
