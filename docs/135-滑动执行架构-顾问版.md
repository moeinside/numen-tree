## 2. A1–A5

| 层级 | 定义 | 示例 |
|---|---|---|
| A1 | 宏任务，决定今天怎么活 | 活过这一天 |
| A2 | 领域级，每日排班 | 战斗/采集/觅食/建造/守护 |

完成上移，失败下滑。

## 3. 运行机制

### 每日排班 + 直觉插入

```text
每天天亮 A1 打分 → A2 领域权重（今日 Todo）
第一 tick 下滑 A2 → A3 → A4/A5
紧急情况跳过常规层级，插入当前上下文
反射结束后感知校验：
  目标仍可行 → 恢复
  环境结构性变化 → 回退 A1 重排
```

### 打分变量

```text
基础需求压力（饥饿/疲劳）
基地资源压力（树工具辅助）
分时段权重（白天采集/黄昏回家）
环境惩罚（天气/地形/群系危险）
```

## 4. 异常处理

### 反射边界

```text
绝不抢占 Numen 底层反射
反射中树指令挂起
反射结束先做前置条件校验
  → 恢复原任务
  → 或换目标 / A1 重排
```

### 失败回退分类

```text
自然失败：A3 失败 → A2 内换 A3，不触发 A1
结构性失败：A2 内全失败 / 环境根本变化 → A1 重排
```

## 6. 风险（重点）

### Lua 槽堵塞/僵尸锁

```text
单线程槽一旦卡住，后续指令全堵
防御：串行下发 + 超时 + 空闲预检 + 僵尸锁扫描清理
```

### 重排班过频

```text
小挫折就 A1 重排 → 每秒重算，另一种抖动
防御：严格区分自然失败/结构性失败
```

### 失败死循环

```text
没武器 → 逃跑 → 饿死 → 重排又砍树
防御：领域失败负分/CD + panic_shelter 保底
```

### 恢复错位

```text
被怪追跑 30 格后恢复砍树，原地空挥
防御：恢复前校验坐标/距离/工具耐久
```
