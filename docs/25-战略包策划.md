# 25. 战略包策划（小步版，先不做大工程）

> 目标：按游戏内常见玩法，把"同伴日常会做的事"拆成一批**小战略包**（L2/L3，单一交付物/可验收），
> 每个只调用已验证战术；不包含建基地、农场、多同伴黑板等大任务。

## 2. 优先级与实现批次

### Phase 1（P0/P1，生存闭环，当前优先）
1. `eat_to_recover`（L2）——低血/饥饿时恢复（食物暂不紧缺，但低血兜底）
2. `sleep_through_night`（L2）——有床就睡，省掉夜间风险
3. `return_home`（L2）——夜里/远走时回家（night_hold 复用）
4. `equip_upgrade`（L2）——武器/工具切换（护甲后续）
5. 把 `secure_gear / night_hold` 注册成仲裁候选

### Phase 2（P2，基地过夜）
6. `light_base`（L2）——火把/放火把
7. `prepare_for_night`（L3 协调器）——床→光→燃料→上报
8. 燃料链 `mine_coal` / `smelt_charcoal`（后续）

### Phase 3（P3，资源/制造）
9. `make_item` v2（递归依赖）
10. `gather_block`（搜索+采集+背包满处理）
11. `stockpile_wood` / `stockpile_stone`
12. `smelt_items` / `cook_food`

### Phase 4（P4/P5，扩展）
13. `hunt_food`、`clear_hostiles_near`、`travel_to_place`、`follow_owner`
14. `defend_area`、`organize_chest`、`explore_area`（暂缓）

﻿## 7. 工作台/箱子规则实现（2026-11-09 00:1x）

- `ensureWorkbench`：附近有台→走过去开；背包有台→放下开；没有→现做台再放/开。
  已用于 `make_item` / `craftWoodenGear` / `make_charcoal`，修掉"有工作台物品却不去放"的合成失败。
- 配方材料 tag 解析：`planks(any)` / `#minecraft:planks` 等按背包里实际木板/原木计数，不再逐个查 11 种木头（避免战术预算耗尽）；单测覆盖。
- 缺料先查箱子：`make_item` 查表发现缺料 → 找最近箱子 → `scan_container` → `fetch_batch` 取缺的材料，再合成。
- 用户规则落地：采集素材优先 `store_materials` 存箱；工作台制作先查表，缺料从箱子取（v1 最近一个箱子）。
- 测试：战略 **62/62**。
- 后续：把"采集→回家存箱→查表→取料→合成"做成固定流水线（现在分在 store_materials + make_item 两步）。
