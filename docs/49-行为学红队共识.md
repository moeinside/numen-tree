# 49. 行为学红队共识：从“像人”收敛到可证伪的行为底线

> 2026-11-10。三轮行为学评估（R1 行为批判 → R2 技术细节反驳 → R3 共识）。  
> 角色：严苛人类行为学家；不了解实现细节。  
> 结论：**有条件同意：先 bounded rational survival，再谈拟人；A/B/C/D 必须带准入阈值。**

## 1. 行为学 R1 的主要批评

- 行为像“值班表工人”：天亮干活、天黑守夜、被打断挂起；
- 长期目标只是计数器 + checkpoint；
- 习惯只是 SOP 队列，无习惯强度；
- 动机只有需求加权，无 mood/享乐价值；
- 疲劳不落到表现层，全天恒速；
- 恢复免费、切换固定阈值、无机会成本；
- 无探索、无风险态度、无玩家模型；
- 验收只看任务完成，不能证明“像有个脑子”。

## 2. R2 修正

作者用实际细节反驳后，行为学家撤回：

- “疲劳只是需求项”不成立：疲劳是累积压力池，参与候选；
- “无注意”不成立：salience/focus/captured + 本能硬信号已有；
- “动机无短期动态”不成立：satiation/不应期已有；
- “昼夜二值”不成立：实际七时段。

改判为“有惊吓反应与短期饱和的排班工”。

## 3. 仍坚持的架构级风险

1. 疲劳没有落到**表现层**：只影响选什么，不影响做得多好/多快；
2. 无 mood/hedonic，无跨时段心境；
3. 恢复语义有实质缺陷（17s 抖动是结构信号，不是小 bug）；
4. 进度谓词是“架构允许”而非“强制”；EWMA 会拿代理量当成功信号，学到刷分策略；
5. 无风险态度、探索弱、无玩家模型；
6. 缺机会成本抢占。

## 4. P0 共识：四项行为底线

### A. 恢复语义

- 恢复前一次世界观测门槛；
- blocked 计入分母；
- 同意图重试 ≤2；
- checkpoint 加意图标签（在做什么/为什么/预期下一步）；
- 指标：恢复后 60s 内切换、重复动作比、抖动复发率。

### B. 谓词化进度 + evidence

- 每个 milestone 至少一条终态谓词；
- 无进展看门狗；
- 谓词必须含不可由单动作满足的约束（站点现场校验/放置位置/燃料）；
- 语义审计，防 EWMA 学刷分；
- 指标：谓词达成率、计数器-世界背离率、无进展天数、进度归因正确率。

### C. 失败三分 + 归因

- 可重试 / 换策略 / 求助；
- 换不同策略，不重复同一动作；
- 指标：同策略重试率、切换多样性、求助前尝试次数分布。

### D. 疲劳 → 表现乘子

- 作用在时长/失败率/阈值；
- 加收工/休息决策；
- 指标：动作时长随疲劳斜率、夜间效率比、疲劳-休息相关、风险暴露随疲劳。

## 5. 行为学家最后条件

1. **A/B/C/D 的指标必须是准入门槛，不是报告数据**：
   - 每项预设可证伪阈值；
   - 留出种子 + 扰动下判定；
   - 未通过不提升版本号。
2. **极低预算探索与死亡预算联动**：
   - 探索死亡单独记账；
   - 不得超过总死亡预算固定比例；
   - 否则“非零探索”与“死亡有界”互相冲突。

## 6. 后置的拟人层

- 习惯强度；
- mood/hedonic；
- 社会认知/玩家模型；
- 拟人风险态度；
- 通用探索；
- 通用 Planner。

## 7. 行为验收（叠加任务验收）

- 谓词达成率 / 计数器-世界背离率；
- 同策略重试率 / 切换多样性；
- 恢复延迟 / 续做保真度 / 恢复损耗；
- 疲劳-表现斜率 / 夜间效率 / 风险暴露随疲劳；
- 探索死亡占比；
- 留出种子与扰动下稳定。

## 8. 一句话

> **P0 不要求像人，要求行为可解释、可学习、不测 bug、不刷计数器；拟人层后置，但 A/B/C/D 与探索死亡预算必须现在设门槛。**
