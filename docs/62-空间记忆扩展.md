# 62. 空间记忆扩展：地址簿 → SpatialMemory

> 2026-11-10。现有 `places`（命名地点）+ `worldmem`（容器/资源点）需要扩展，但不建议塞成一个大地址簿。

## 1. 现状

### places.json

命名地点：

- `base` 基地
- `death` 死亡点
- `owner` 主人位置
- `poi` 普通地点
- `custom` 自定义

特点：只做命名/模糊解析/按 kind 取；没有安全评分、时效、证据、区域。

### world.json

- `containers`：位置 + 内容 + updatedAt；
- `resources`：wood/ore/animal/water/chest/poi + 位置 + updatedAt；
- 只做存储/距离排序，不做价值判断。

缺：

- 危险地点/危险时段；
- 长期安全点/庇护所评分；
- 地形可通行性；
- 资源量/是否耗尽/可再生；
- 记忆时效、置信度、证据；
- 区域（不只是点）。

## 2. 建议分层

不要一个文件。统一门面 `SpatialMemory`，底层四类：

```
SpatialMemory
├ places        命名地点（base/safe/death/owner/waypoint/...）
├ resources     资源点/容器（量、时效、耗尽）
├ dangers       危险事件/区域（临时、衰减）
└ terrain       稀疏地形/可通行性（只存走过的区域）
```

### 2.1 places 扩展 kind

新增：

- `safe`：长期安全点（可多次使用）；
- `shelter`：临时庇护所；
- `waypoint`：路点；
- `mine_entrance`：矿洞入口；
- `farm`：农田；
- `portal`：传送门；
- `landmark`：地标。

安全点评分字段：

```text
safePoint {
  pos, dimension,
  shelterScore,      // 有顶/围护/光照
  defensibility,     // 易守难攻
  capacity,
  waterDistance, foodDistance,
  lastVerifiedAt, ttl,
  confidence, source
}
```

### 2.2 resources 扩展字段

```text
resource {
  kind: wood|ore|animal|water|chest|farm|...
  pos, dimension, area?,
  countEstimate,
  clusterSize,
  renewable,
  depleted,
  lastSeenAt(gameTick),
  ttlGameTicks,
  confidence,
  source, evidence
}
```

规则：

- 只记“看见/到过/操作过”的；
- 资源可耗尽 → `depleted` 或降低 confidence；
- 可再生（树/动物/农场）要标；
- 查询时按距离 + 新鲜度 + 置信度排序。

### 2.3 dangers 独立层

危险不是永久地点，是有时效的区域/事件：

```text
danger {
  kind: hostile|lava|water|cliff|dark|trap
  pos, dimension, radius,
  severity,
  lastSeenAt(gameTick),
  expiresAt(gameTick),
  source,
  evidence
}
```

用途：

- 规划绕行；
- 夜间/低血时提高权重；
- 过期自动降级；
- 不用于“全知透视”，只记亲眼/亲身遭遇。

### 2.4 terrain 稀疏地形

不要存每格方块。只存：

- 走过的 chunk/region 摘要；
- 可通行边/障碍（水/岩浆/悬崖）；
- 地标/洞口；
- `lastSeenAt` + `ttl`。

```text
terrainPatch {
  dimension,
  bounds / center+radius,
  features: { water, lava, cliff, open, shelter },
  traversability: { edges? },
  lastSeenAt, ttl, confidence
}
```

用途：

- 找路、判断能不能下去；
- 避免重复扫描；
- 不能替代现场校验。

## 3. 统一查询

`SpatialMemory` 提供：

```text
nearestPlace(kind, pos, {fresh})
nearestResource(kind, pos, {minConfidence})
nearestSafePoint(pos, {threat, night})
dangerNear(pos, radius)
terrainAround(pos, radius)
remember*()
verify*(pos) // 使用前现场校验
forget/decay()
```

排序：

- 距离；
- 新鲜度/TTL；
- 置信度；
- 安全评分/危险惩罚；
- 资源量/可再生。

## 4. 信息边界

- 只记访过/看过/操作过的；
- 危险/资源带 `lastSeenAt`，过期降级；
- 使用前现场校验，不能远程确认；
- 不存全图/未访问结构/矿脉透视；
- LLM 只看树压缩后的摘要。

## 5. 与现有模块关系

- `places` 保持“命名地点 + 模糊解析”，只扩 kind 与安全评分；
- `worldmem` 保留容器/资源，补时效/置信度/耗尽；
- 新增 `dangers`、`terrain`，不要塞进 places；
- 统一由 `SpatialMemory` 门面读写，避免战术层直接翻文件；
- 观测/动作结果更新 SpatialMemory；使用前 `PerceptionService` 校验。

## 6. 落地顺序

### P1（便宜、立刻有用）

1. `places` 加 `safe/shelter/waypoint`；
2. `worldmem.resources` 加 `countEstimate/depleted/lastSeen/confidence`；
3. `dangers` 最小层（hostile/lava/water/cliff + ttl）；
4. `SpatialMemory` 门面 + nearest 查询。

### P2

5. 安全点评分/选择；
6. terrain 稀疏 patch；
7. 资源耗尽/再生更新；
8. 危险绕行接入 Planner。

### 暂不做

- 全图地形存储；
- 未访问结构/矿脉透视；
- 大规模地图数据结构；
- 多同伴共享记忆（后置黑板）。

## 7. 一句话

> **地址簿只负责“命名地点”；资源、危险、地形、安全点应分成独立层，由一个 SpatialMemory 门面统一查询与校验。**
