# 76. Day1 合并设计（待点子王质询）

> 行为学家 + MC 专家合并稿；总控只加架构约束。  
> 目标：可执行、可判负、不过拟合；不写代码。

## 1. 入口策略

空背包/未知时，不写“第一步撸树”：

- **A 有可见树**：默认倾向触发，采最近可及树；不生成“找树”目标。
- **B 无可见树**：升级为有预算的定向探索（扇区/2~4 跳，约 3 min），每跳查原木；不是 gather。
- **C 紧急覆盖**：低血/夜/水/威胁 → 反射/硬门优先。

“找树”语义：

```
默认倾向 = 未知下偏好低风险、就地、能换取信息的动作
搜索子目标 = 默认倾向失败后的后备，有预算/超时
```

看不到树：

```
探索 → 2 次无发现 → 换方向/地形 → dusk 仍无 → 转夜间保底
```

**不允许无限探索。** `log_unseen=unknown`，不能写“没有”。

## 2. 结果型 milestone

- **M1 有木**：原木 ≥4，能产出木板/木棍（谓词：原木/木板/木棍计数）。
- **M2 有工作台**：工作台已放置且 L1 现场可交互（不是“造过”）。
- **M3 有可用工具**：至少一件木工具在包，且**实际使用过一次**：
  - 优先证据：手持木斧砍树后原木/掉落增量；或手持木镐采石后圆石增量；
  - 无耐久字段，不按“快坏了”判断。
- **M4 夜间安全**：入夜后 HP 无下降、无死亡、无新增贴身敌对；至少一项保底：
  - 食物存量 ≥2 或饥饿 ≥14；
  - 火把/木炭 ≥1 且点燃；
  - 可进入的封闭庇护。

**只是手段，不是 milestone**：找树、走向树、合成木板、找煤、杀动物、挖洞、石工具、木→石升级。

## 3. 硬门（字典序）

生命 > 行动能力（脱困） > 饥饿 > 夜间暴露 > 资源 > 建造。

- 溺水/贴脸威胁/低血：反射抢占；
- 饥饿 <6：覆盖除反射外所有计划；
- HP<8 且饥饿<8：只允许进食/撤回安全点/休息；
- HP<10：禁下水、禁下矿、禁战斗；
- 饥饿 <14：提前启动食物准备（不要等饿到 4）；
- dusk 剩余约 30%：停止开新采集，转 M4 保底。

## 4. Day1 行为序列

- **黎明**：观测 + A/B 入口；
- **上午**：木≥4 → 工作台；
- **午后**：木工具 + 食物准备交替（单槽，不并行）；
- **下午中段**：食物保底优先于升级；
- **dusk**：收工，转夜间保底；
- **夜**：光照内守夜/整理，禁止远行；饿就吃。

食物主路线：打猎（牛/猪/羊/兔），生肉直接吃（生鸡肉除外）；备选箱子/村庄不作为 Day1 保底。
木→石：**Day1 非必须**，Day2 首个 milestone；Day1 只算加分。

## 5. 失败路径

- 没树：探索预算→换方向→夜间保底；`log_unseen` 保持 unknown。
- 没动物：存货→箱子→腐肉仅饥饿≤2；仍无→减少受伤，接受低饥饿。
- 没裸岩：斜坡向下挖 3~5 格；不做竖井。
- 背包满：只读 used/total，无 slot 信息；按固定低值 id 丢，不能“选最差”。
- 槽被占：让路等待，超时记 blocked；禁止 taskkill。
- 入水：反射 + 触手 dirs 找 standable + avoid cell type；触手 water 穿墙，不能当“岸在哪”权威。
- 观察失败：一律 unknown，超预算上报。

## 6. Fact / 接口

Fact（每条 source/observedAt/ttl）：

- `log_visible`、`stone_visible`、`animal_visible`；
- `table_reachable`、`in_water`、`on_ground`、`food_stock`、`night_safe`、`stuck`；
- `held_tool`、`item_delta`（动作后）。

谓词：

- `logs>=4`、`has_table`、`tool_used`、`food_ok`、`night_no_damage`、`postcheck_ok`。

动作：

- `criticalFacts`（前置）；
- `expectedPredicate`（后置）。

## 7. 总控架构约束

- 不变量不能让步：三态、postcheck、plan≠milestone、L0/L1 动作前置、失败三分、单槽。
- 现在留桩不实现：
  - WorldHints（L2，只 explore/verify，P0 off）；
  - 结果型 GoalProfile/依赖/回退；
  - SpatialMemory 查询面；
  - CompanionKnowledge 溯源；
  - 观察预算/注意、状态快照/恢复、决策理由记录；
  - 多同伴 sender/version。
- 不能写死：坐标、树种/biome、固定第一步/路径、食物来源、半径阈值、单 biome 假设。
- 可以固定 SOP：木→板→台→木工具顺序、夜间三选一优先级、硬门、失败降级顺序。
