## 目标

战略表不只向下执行，还能在目标缺前置时**向上回推**：

```
铁镐 → 铁锭 → 铁矿 → 石镐 → 圆石/木棍/工作台
```

## 设计

- 方法库：`goal + requires + steps + produces`，覆盖合成/熔炼/采矿/采集；
- `expandGoal(goal, facts)`：有界递归补缺；
- 去重、环检测、深度/节点上限；
- 输出 `resolved / unresolved / blocked`；
- profile milestone 可声明 goal；缺子目标 → 插入子 milestone，父暂停/checkpoint；
- 子完成恢复父；子失败降级/求助，不无限递归；
- 不确定动作（找矿/水/食物）允许“探索/玩家干预”出口。

## 阶段

1. 扩展 method 表：铁/金/钻石、通用 smelt、工具前置、中间合成；
2. 有界 `expandGoal`；
3. 接 profile/milestone 暂停恢复；
4. 补探索/求助/失败降级。
