# 33. 北极星：给 numen 的具身身体装一个模拟脑

> 2026-11-09 用户定义。整个项目 = 给 numen 具身身体装一套**模拟脑**；numen 本身保留延髓/反射/动作，项目只补少量缺失的“延髓神经”。
>
> **术语说明**：这里说“模拟脑”，是指项目要实现的一整套脑功能模拟层，不特指解剖学上的“大脑”；大小脑、脑干等是这套模拟脑内部的功能分区，避免“大脑”一词与具体脑区混淆。

## 1. 一句话北极星

**给 numen 的具身身体装一个能自主生存、能被高层意图引导的模拟脑；numen 保留延髓反射与身体动作，项目只补少量缺失的神经/感知/修锁能力。**

## 2. 分层映射

| 生物层 | 项目层 | 归属 |
|---|---|---|
| 身体、脊髓、运动神经元 | 原子动作/移动/战斗/交互 API | **numen** |
| 延髓/脑干反射 | numen 内置反射（Flee/Defense/MLG/Unstuck/Breath） | **numen**，树让路 |
| 感觉神经（视/触/本体） | 触手 mod（只读感知/地形） | **项目补的神经** |
| 延髓维修 | lockfix（清锁/清内置脑任务/技术诊断） | **项目补的小修补** |
| 脑干/小脑 | 战术包、执行监督器（节点评估/纠错） | **树** |
| 基底节 | 优先度/仲裁（选择、承诺、抢占、恢复） | **树** |
| 前额叶 | 战略包/计划/工作记忆 | **树** |
| 海马/皮层 | 地点簿、世界记忆、黑板 | **树**（后置） |
| 皮层（语言/推理） | LLM / 树工具前置 | **外部模型 + 前置层** |

## 3. 边界规则

1. **不重造身体**：移动/战斗/交互/合成执行继续借 numen，不在树里发明动作 API。
2. **延髓让路**：numen 反射/本能仍最高优先；树负责让路、观测、恢复，不硬刹。
3. **神经要小**：触手只做感知，lockfix 只做技术修复；不发展成第二套运动系统。
4. **脑归树**：需求、优先级、战术/战略、记忆、恢复归树。
5. **LLM 是皮层顾问**：不参与实时反射，只做意图/高层判断；慢/断连时树继续生存。
6. **补神经不等于补脑**：mod 可以做眼睛/修锁，不做“我该做什么”。

## 4. 北极星指标（建议）

不再只看“完成多少任务”，而看“这个大脑是否成立”：

- **自主生存**：无指令下能活过夜晚、补装备、找食物；
- **行为连贯**：承诺执行，不乱切任务；
- **可恢复**：卡住/锁死/死亡后能自己恢复或降级；
- **可被引导**：主人/LLM 的意图能改变方向，但不破坏安全；
- **边界干净**：numen 动作/反射不被重复实现，mod 不越权。

## 5. 非目标

- 重写 numen 的身体/寻路/战斗；
- 用 mod 替代大脑做决策；
- 纯脚本机器人；
- 无边界地堆动作 API。
