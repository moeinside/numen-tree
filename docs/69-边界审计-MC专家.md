# 69. 边界审计（MC 专家）：numen / 触手 / 项目红线

> 2026-11-10。MC 专家只读审计 WORLD-CONSTRAINTS、numen 文档/源码、触手 Java 后结论。  
> 重点：触手 v0.3 不是“可能穿墙”，是**确定无 LOS/FOV 的方块扫描**；必须降级为候选，不能当权威。

## 1. 结论

- MC 专家**确实掌握** numen/触手细节，且能指出文档错误；
- 但之前的 `WORLD-CONSTRAINTS` 有过度/不足；
- 触手 v0.3 的 `water` / `landmarks` 与项目“禁止穿墙探测”红线冲突；
- 树侧还有确定性 bug：`self.food=null` 被 `Number(null)===0` 误读为“饥饿 0”。

## 2. 触手 v0.3 实际边界（源码级）

### 能给

- `self`：uuid/name/pos/yaw/pitch/hp/max_hp/food(仅 player)/dimension/light/day/day_time；
- `terrain`：in_water/in_lava/on_ground/feet/head/above/below/dirs；
- `water`：open_count/ice_covered_count/nearest_open/nearest_ice；
- `entities`：type/category/pos/distance/limit；
- `landmarks`：5 类（chest/bed/torch/crafting_table/furnace），最多 20；
- `limits`：radius/vision_range/fov/limit；
- `tick`。

### 不能给

- 背包/手持/护甲/饱和度/氧气/天气；
- 容器内容/矿脉/石头/log 方块；
- 实体掉落物 id；
- 上下坡高差；
- 记忆/来源/时间戳/置信度。

### 确定缺陷

1. **landmarks 零 LOS/FOV**：玩家周围 ±10 水平、-3..+4 垂直全方块 `getBlockState`；确定穿墙。
2. **water 零 LOS/FOV**：固定 r=16、y -4..+3 全方块扫描；确定穿墙；open_count 是方块数不是面积。
3. **entities**：
   - 夜间 `maxRange=min(radius,16)`，白天才用 radius；
   - 4.5 格内免 FOV；LOS 只对 LivingEntity；
   - `category` 类继承近似：slime/phantom/ghast/shulker 漏 hostile；鱼不算 animal；hoglin 算 animal 但敌对；掉落物占 other 名额；
   - limit 20/上限30，按距离截断。
4. **self.food 仅 player-like**：非 player 给 null；树侧 `Number(null)===0` 会把 null 误读为饥饿 0。
5. 单线程 accept + 2s latch；游戏卡顿会 timeout。
6. 无 source/observed_at/confidence。

## 3. numen 边界修正

- 确认：单程序 200 次 API 调用上限；`task.timer` URGENT 会打断；`get_events` 不吃 Lua 槽（槽被占仍可观测）。
- 确认：`inv.make` 3×3 自动找 16 格内台子；没有则用背包台子自动放身旁。
- 确认：无耐久/护甲数组/经验/攻击力字段；有 air/max_air。
- 未验证：生肉 `inv.eat`、`work.dig` 流体限制、route 默认游泳/avoid 全值表、scan.blocks 上限。
- 修正：`avoid` 用 cell type（water/flowing_water），不是 block id；但全量值表未确认。

## 4. 立即决策（树侧）

1. **触手只做候选/近身辅助，不做权威**：
   - `landmarks/water` 不进入权威 Fact；
   - 使用前必须现场校验；
   - 不做战斗/容器判断。
2. **威胁权威 = numen `scan.entities("hostile")`**；触手只做近身提示。
3. **食物权威 = numen status/inv**；触手 `food` 仅作可选辅助，且必须 `s.food != null`。
4. **树侧修 null 误读**：`Number.isFinite` 前先排除 null/undefined。
5. **landmarks/water 在 v0.4 加 LOS/FOV，或降级为“已探索记忆”**；在改之前，不用于避水/找箱。
