# 80. 开发工具共识：Pilot + Recorder + Cheat（延后）

> 2026-11-10。六位顾问质询 docs/79 后的 Lead 收敛。  
> 结论：**方向可行，但不在当前范围；Day1 出线前不建 pilot/cheat provider。**

> 2026-11-10 修订：玩家澄清 pilot 是“人工批准下的实时观测/纠错参考”。见 `docs/81-Pilot参考运行.md`：  
> **pilot 可提前到 Day1 期间作为 Track B 参考运行；cheat 仍延后；Track A 验收不受影响。**

## 1. 总体结论

- **LLM Pilot + Recorder**：方向可行，属 Day1 出线后的开发工具；
- **Dev Cheat Bridge**：可做，但必须独立信任域、fixture 期使用、禁止 run 中作弊；
- **当前不做**：Day1/early_survival 未落地，先建捷径会替代真实能力验证；
- **“一个工具”要拆**：
  - pilot + recorder：同生命周期，可在一个工具；
  - cheat：独立模块/进程/构建，不与被测系统同可信域。

## 2. 共识表

| 角色 | 结论 | 关键条件 |
|---|---|---|
| 总控 | 有条件同意 | cheat 只能改世界，不能改认知/证据；pilot 产物不进树/验收/学习 |
| 产品经理 | **反对当前纳入范围** | Day1 出线后再做；MVP 只 recorder+stop+backup/restore+审计 |
| 行为学家 | 有条件同意 | 场景布置可，过程援助不可；作弊段样本作废 |
| MC 专家 | 有条件同意 | 单机无 RCON；仅 fixture 期 cheat；离线快照；RCON 需另开 gate |
| 点子王 | 有条件同意 | 构建期隔离、mod HTTP 优于 RCON、pilot/cheat 拆进程 |
| 玩家代表 | 有条件同意 | 可展示但要标注；只能产事实/回归/假设，不能产“它能自己活” |

## 3. 现在不做

- 不做 LLM pilot；
- 不做 RCON/mod cheat provider；
- 不做 scanWorld；
- 不做 snapshot/restore（未定型）；
- 不做 review pack 自动化；
- 不把 cheat 纳入 Day1/P0。

## 4. Day1 出线后的顺序

1. recorder 扩字段 + stop/settle + manifest；
2. 备份/restore + 世界哈希验证；
3. 标签/审计过滤（证据侧硬拒绝）；
4. LLM pilot（无 cheat）；
5. fixture 期 cheat（Mock → 一个白名单 provider）；
6. scanWorld/WorldHints 另开 gate。

## 5. 未来 cheat 边界

### 允许（仅 fixture 期）

- 白名单执行，不是黑名单；
- 给资源、设置时间/天气、生成实体、摆测试位；
- 独立测试世界 + 独立 places/goalstore/trace 目录；
- 每次操作带 runId/reason/manifest；
- 报告自动标“不可用于 Day1/P0”。

### 禁止

- run 中给资源/传送/回血/改难度；
- `gamerule`/`difficulty`/`peaceful`/`effect`（会伪造夜间/食物通过）；
- `kill @e`/`clear`/`data merge block`/`fill`/`clone`/`forceload`；
- 改同伴决策/记忆/内部状态；
- scanWorld 进运行时；
- 作弊产物进 learning/记忆/验收；
- 生产配置/生产世界启用。

## 6. 信任域

```text
可信域 A：pilot + recorder
  - 正常操作/日志/证据候选（但 pilot 仍不进验收）

可信域 B：cheat
  - 独立进程/独立构建/独立世界
  - 只操纵世界，不接触 A 的 facts/决策
  - 事件独立 channel，审计硬拒绝
```

**“无作弊”必须可反证**：manifest + 构建证明 + 配置扫描 + trace 零 cheat，不能只靠报告里写一句。

## 7. 对原提案的修正

- 不叫“为未来功能留捷径”；改为“fixture 期作弊能力，逐项新提案”；
- RCON 不首选：单机无 RCON；专用服另开 gate；
- scanWorld 不做：vanilla RCON 不能批量扫描，mod 扫描另属 WorldHints；
- pilot 只作上限对照，不得成为调参目标；
- 一个工具改为“一个产品族，两个信任域”。

## 8. 一句话

> **工具方向可行，但先让 Day1 出线；pilot/recorder 可以同工具，cheat 必须独立域；作弊只能产夹具与对照，永远不能产“它能自己活”的结论。**
