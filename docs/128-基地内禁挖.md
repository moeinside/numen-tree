# 128. 基地内禁挖（P0 空间保护）

> 2026-11-11。MC 专家口径 + 最小实现。  
> 触发：同伴在基地内自主挖矿，改变环境，引入反射/寻路死锁。

## 1. 基地判定

```text
3D bbox，不是点+半径
多个基地取并集，任一命中即禁
```

默认：

```text
所有 base/home → 水平 half=5（10×10）
垂直 y-5 .. y+5（10 高）
place.radius 存在时覆盖水平默认
```

当前阶段先统一 10×10×10；更精细的 role/bbox/外部触手识别放 P2/P3。

## 2. 拦截层

已实现：

```text
dig_nearby：扫描候选时过滤基地内方块
mine_nearby：簇内方块过滤基地内
dig_cells：精确目标过滤基地内
```

命中后：

```text
kind = refused
不进失败预算
不触发 abandon
```

未实现：

```text
atom.dig_one / atom.dig_cluster 的兜底校验
显式 task/llm 的 allowBase 放行
build/pave 等其它改地形路径
```

## 3. 自主 vs 显式

当前实现默认**自主挖禁**；显式放行尚未接。

后续：

```text
auto            → 禁
task/llm 显式   → 允许，标 explicit
脱困/封口/避难  → 白名单，不走采矿守卫
```

## 4. 缺失/过期

```text
完全无 base/home 记录 → fail-open（否则 Day1 开局不能挖）
有记录 → 按 bbox 禁
isTest → 自主禁、显式放行（待接）
```

## 5. 验收

```text
基地内自主 dig/mine → refused，失败预算不增长
基地外正常挖 → 成功
dig_cells 基地内 → refused
无 base 记录 → 不误伤
```

判负：

```text
基地内出现自主挖掘 atom begin
基地外被误拒
refused 计入失败预算并导致 abandon
```
