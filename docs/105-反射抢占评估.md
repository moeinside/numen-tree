# 105. 反射抢占 / 生存-发展互斥评估（三顾问）

> 2026-11-11。`mc-expert` + `behaviorist` + `idea-king`。  
> 输入：用户提出的“无武器遇怪逃跑反射过高，导致资源任务死锁”及外部建议。

## 1. 共识

- **不改反射层**，不违反“反射不可抢占”的硬边界；
- **禁止** `force_hold` / `lockfix` 卡死反射来压过安全；
- 反射可以不可抢占，但**必须可观测**：每次抢占进 trace，关联被打断的 goal、副作用、恢复路径；
- “苟到白天”可以是正确避险，但**不能是终态**；必须有退出、收敛、升级。

## 2. 对原建议的修正

| 建议 | 结论 |
|---|---|
| 木棍算临时武器 | **错**：木棍攻击力等同空手，是骗判定 |
| 木剑 | **对**：1 原木 → 4 木板 + 木棍 → 木剑，最便宜破局 |
| 边逃边砍 `evasive_gather` | **不可行**：单动作槽不能同时移动+挖 |
| 挖三填一 | 可行，但优先**侧向 1×2 洞 + 封口**，避免竖井出不来 |
| 覆盖反射 | **危险，否决**：会连带废掉溺水/岩浆/坠落保护 |
| 白天捡漏 | 可行但本质是等，收益低 |
| 死锁夹具 | **应加，但改名 `Fixture_Reflex_Preempt`**；“死锁”是待证结论，不是输入前提 |

## 3. 最小破局动作集

1. **武器线优先于采集线**：1 原木先做木剑，有武器后逃跑反射大概率解除；
2. **换工作点**：flee 后不回原地，敌对 >0 不开新长动作，先到光照开阔处；
3. **panic_shelter**：hp≤8 或夜间无武器时，侧向 1×2 洞 + 封口，作为有界终态。

## 4. 夹具：Fixture_Reflex_Preempt

必须两臂：

- **可解臂**：存在安全窗口/资源；预算内应完成木剑或进入封闭安全态；只苟不发展 → 判负；
- **不可解臂**：真封锁；允许“有度量的失败”，必须 `abandon/blocked` + reason；只苟 → 判合格失败，不算通过。

判负：

1. 白天结束既无木剑也无封闭安全位，且无 abandon/blocked；
2. 同一反射触发 ≥3 次仍在同一区域，无位移/策略切换；
3. 夜间 HP 下降或死亡；
4. 用 force_hold/lockfix 覆盖反射；
5. 若白天敌对是注入，必须独立 oracle 证明并标缺陷场。
