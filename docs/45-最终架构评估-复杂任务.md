# 45. 最终架构评估：四类复杂任务逐层剥离

> 2026-11-09。抛开钓鱼/吃饭链，选四类常见复杂任务评估目标架构：
> ProfileManager + milestone + bounded Planner + Arbiter + ResourceLedger + Executor + Reflex。
> 结论针对**单同伴**。

## 场景 A：铁器时代（工具升级链）

### 顶层目标

`profile: iron_age`：从石制工具升级到铁镐/铁剑，并保留备用。

### 逐层剥离

| 层 | 内容 | 架构能否表达 |
|---|---|---|
| milestone | 石镐 → 熔炉+燃料 → 挖铁 → 烧锭 → 铁具 → 换装/备份 | ✅ Profile |
| 方法 | craft(石镐/熔炉/铁具)、mine(铁)、smelt(锭)、equip | ✅ 方法库 |
| 前置 | 工作台/镐/燃料/铁矿/炉 | ✅ Facts/Readiness |
| 失败 | 没矿→探索/换点；没燃料→木炭/木板；没炉→造；没台→造 | ✅ 有界 Planner 降级 |
| 中断 | 夜晚/低血/被追→反射/优先度抢占，milestone 暂停 | ✅ 中断/恢复 |
| 资源 | 工作台/炉/箱子/铁锭共享，避免重复造 | ⚠️ 需 ResourceLedger |
| 验收 | 铁镐+铁剑+备用各≥1 | ✅ milestone acceptance |

### 结论

**架构可实现。** 主要风险不是架构，而是：

- 铁矿是否存在/可达；
- 燃料够不够；
- 挖矿/熔炼执行成功率；
- Planner 回推深度（不要无限递归）。

覆盖度：架构 80%，当前实现 30%。

## 场景 B：建安全屋/基地

### 顶层目标

`profile: base_build`：选址→材料→围护→门/光→床/箱→验收。

### 逐层剥离

| 层 | 内容 | 架构能否表达 |
|---|---|---|
| milestone | 选址 → 备料 → 框架 → 围护 → 门窗 → 照明/床/箱 → 验收 | ✅ Profile |
| 方法 | 采集、合成、放置、挖平、铺路 | ✅ 方法库（需要 build 方法） |
| 前置 | 工具、材料数量、地面可建、空间 | ⚠️ 需地形/蓝图 Facts |
| 失败 | 地形不平→挖/垫；材料不够→补；位置危险→换址 | ✅ Planner 降级 |
| 中断 | 夜晚/袭击→暂停；天亮继续 | ✅ checkpoint |
| 资源 | 材料消耗、工作台、箱子 | ⚠️ ResourceLedger |
| 验收 | 有墙/顶/门/光/床/箱，可入睡 | ✅ 可定义 |

### 结论

**架构结构上可实现**，但需要：

- 建筑方法库（蓝图/放置/支撑/防塌）；
- 地形可建性判断；
- 长任务分段与验收。

没有“建筑方法库”时，架构不会自己长出建造能力。  
覆盖度：架构 75%，当前实现 20%。

## 场景 C：开农场（跨天生产）

### 顶层目标

`profile: farm`：选地→水源→锄地→种子→种植→等待→收获→储存。

### 逐层剥离

| 层 | 内容 | 架构能否表达 |
|---|---|---|
| milestone | 选址→引水→开垦→播种→等待成熟→收获→入库 | ✅ Profile |
| 方法 | 挖/放水/锄地/播种/等待/收获 | ⚠️ 需要农业方法库 |
| 前置 | 种子、水、光照、土、时间 | ⚠️ 需作物/时间 Facts |
| 失败 | 没种子→找/换作物；没水→引水；被踩/被吃→围护 | ✅ Planner 降级 |
| 中断 | 跨天等待；夜晚/袭击暂停；成熟后回来 | ⚠️ 需要 “wait until condition” milestone |
| 资源 | 水/种子/箱子 | ⚠️ ResourceLedger |
| 验收 | 成熟作物收获入库 | ✅ |

### 结论

**架构可实现，但需要“跨天等待/条件唤醒”机制**。  
否则 profile 会一直轮询，或忘记回来收获。  
覆盖度：架构 70%，当前实现 10%。

## 场景 D：找村庄/远征探索

### 顶层目标

`profile: find_village`：探索→发现村庄→补给/交易/床→返回或建立前哨。

### 逐层剥离

| 层 | 内容 | 架构能否表达 |
|---|---|---|
| milestone | 出发→探索扇区→发现结构→接触→补给→返程 | ⚠️ 探索不是确定任务 |
| 方法 | 旅行、扫描、记忆、返程 | ⚠️ 需世界记忆/地图 |
| 前置 | 食物、武器、安全路线、回家锚点 | ✅ Facts |
| 失败 | 找不到→扩大搜索/返回；太远→放弃；夜→扎营/回家 | ⚠️ 需探索预算 |
| 中断 | 反射/夜晚/死亡 | ✅ |
| 资源 | 食物/装备消耗 | ✅ Readiness |
| 验收 | 发现村庄/回到基地 | ⚠️ 概率性 |

### 结论

**架构只能部分实现。**  
“找村庄”不是确定性生产任务，需要：

- 世界记忆/地图；
- 探索预算与返程策略；
- 找不到时的求助/放弃；
- 多同伴/黑板更好。

覆盖度：架构 50%，当前实现 10%。

## 横向场景：夜间袭击 / 死亡恢复

| 场景 | 预期 | 架构 |
|---|---|---|
| 守夜遇袭 | 反射/guard 优先，长期 profile 暂停 | ✅ |
| 空手守夜 | 回安全屋，不硬打 | ✅ Readiness |
| 死亡重生 | 旧计划作废，装备检查，重新规划 | ✅ |
| 基地被破坏 | 重新评估缺口，修复/重建 milestone | ✅（需 build 方法） |

## 总体结论

### 架构能覆盖

- 铁器时代（确定性生产链）；
- 安全屋/基地（需建筑方法库）；
- 农场（需跨天等待机制）；
- 夜间/死亡等中断恢复；
- 多 profile 串行、共享前置、资源认领。

### 架构不能单独覆盖

- 开放式探索/找村庄；
- 多同伴/共享黑板；
- 学习/自创战略；
- 没有方法库时的新领域能力；
- numen 执行限制。

### 四类任务覆盖度

| 任务 | 架构覆盖 | 当前实现 |
|---|---|---|
| 铁器时代 | 80% | 30% |
| 安全屋 | 75% | 20% |
| 农场 | 70% | 10% |
| 村庄/远征 | 50% | 10% |

## 最重要的判断

这套架构对**确定性、可分解、有明确验收**的任务是成立的；  
对**不确定性探索、多人协作、学习**不成立，需要额外层。

之前反复推翻的根因不是架构方向错，而是：

1. 没有 Profile/Milestone 层；
2. 没有 Planner，只有 onFail 分支；
3. 没有资源账本；
4. 没有按场景矩阵验收。

建议下一步：

1. 实现 ProfileManager + milestone；
2. 用 `iron_age` 做第一个纵向切片；
3. 补 ResourceLedger；
4. 再评估农场/基地；
5. 探索/多同伴后置。
