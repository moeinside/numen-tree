# 72. 圆桌共识：Day1 从 0 到求生

> 2026-11-10 开发前圆桌。全体六位顾问参加。  
> 结论：**有条件共识，可开工；先按共识改，再跑 Day1。**

## 1. 对玩家判断的修正

玩家判断：

> 问题在“感知 → 需求建立 → 启动任务”。

共识：

- **链确实断了，但断点不是“感知不够”**；
- 真正缺的是：
  1. 结果型 milestone（plan ≠ milestone）；
  2. 前置条件回补；
  3. 未知下也能启动的“入口语义”；
  4. 食物/低血硬门；
  5. 候选可达性预检。

因此：

> **不要扩感知，不要用全知扫描掩盖感知缺陷。**

## 2. 黎明作弊扫描：一致否决运行时

六位一致：

- **禁止进入运行时决策**；
- 不做 Facts 来源，不进 Planner，不进目标选择；
- 只允许作为**离线/测试 oracle**：
  - 只用于审计对照；
  - 不进生产配置；
  - 运行 trace 里出现 oracle 事实 → 该次运行直接判负；
  - 报告必须标“作弊对照”，同日要有非作弊版本。

理由：

- 违反 NORTH-STAR 不变量 8（具身边界）与 2（未知≠假）；
- 会让 Day1 “因错误理由通过”；
- 掩盖真正缺口：入口/结果语义。

多同伴共享世界状态：**过早，P0/P1 前不做。**

## 3. “无脑撸树”怎么建模

共识：

- 不写成“第一步必须撸树”；
- 不写成 milestone（那是把手段伪装成结果）；
- 不写成需求（无压力也会做）；
- 建模成 **默认起始倾向 / 未知下的入口策略**：

> 没有更强候选、资源未知时，选择低风险、就地、能换取信息的动作（就近找树/采集），再根据结果建立需求。

硬编码的是“**凭什么选这个动作**”，不是“固定第一步”。

## 4. Day1 基准（可判负）

起点：

- 固定夹具新世界；
- 0 资源、0 milestone；
- day0 黎明；
- 无 LLM、玩家零干预；
- 运行时无作弊扫描。

终点：第一次日出 / 进入 day2 清晨。

必须：

1. 自己发现树/资源并启动采集（不是靠 oracle）；
2. 原木 ≥4，产出木板/木棍；
3. 工作台放置 + 至少一件木工具产出并实际使用；
4. 入夜前至少一项保底：
   - 食物存量 ≥ 阈值，或
   - 火把/木炭，或
   - 封闭庇护；
5. death = 0；
6. 无 `water_stuck/no_food/craft_failed` 连续超时；
7. 无“动作 ok 但世界没变”（postcheck）；
8. 无 stale/unknown 当确定；
9. 全程可解释、可判负。

不做硬性要求（第一版）：

- 石工具；
- 熔炉；
- 床；
- 3×3 木屋。

## 5. 开发前最小改动

1. 回退/修正 `avoid` cell type 语法（`water/flowing_water`），或先回退避水；
2. 食物/低血硬门；
3. `early_survival` 结果型 milestone（3~4 个）+ `from_zero` SOP；
4. 三态 fact：未知不得当“没有”；
5. 候选可达性预检：不可达不进候选，转定向探索；
6. 默认起始倾向/入口策略；
7. Day1 规格与审计负样本先冻结。

## 6. 明确不做

- 运行时作弊扫描；
- 多同伴/共享黑板；
- SpatialMemory；
- 新战术/战略包（`from_zero` 除外）；
- 硬编码 S0–S7 任务表；
- 调阈值过验收；
- 扩感知层；
- 每日北极星任务（H2 后置）。

## 7. 共识状态

| 角色 | 结论 | 关键条件 |
|---|---|---|
| 总控 | 有条件同意 | 扫描不进目标选择；入口走具身；Day1 先冻结 |
| 产品经理 | 有条件同意 | 扫描仅测试 oracle；Day1 起止/谓词/阈值冻结 |
| 行为学家 | 有条件同意 | 起点=默认倾向；扫描仅离线 oracle；结果谓词验收 |
| MC 专家 | 有条件同意 | 扫描仅测试；感知/可达双源证据；Day1 最小五项 |
| 点子王 | 有条件同意 | 扫描不做；局部普查；2 个 biome 前测 |
| 玩家代表 | 有条件同意 | 不写死撸树；扫描不进决策；零干预+可判负 |

## 8. Lead 决议

- **共识成立，可开工**；
- 先做最小改动，再冻结 Day1，再跑；
- 若实施中把“扫描→生成任务”做成运行时架构，立即停线回圆桌；
- Day1 通过只代表“该夹具可过”，不代表泛化；第二 biome 前测后再说泛化。

## 9. 一句话

> **Day1 不是“先扫描再决定”，而是“未知下敢用低风险动作换取信息”；扫描只能当测试对照，不能当眼睛。**
