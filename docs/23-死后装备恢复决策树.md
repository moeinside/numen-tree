# 23. 死后装备恢复决策树（武器 → 工具）

> 起点：同伴死亡重生，背包清空，第一目标是武器，第二是工具。
> 原则：**不进入死亡循环**；白天优先，夜里先保命；能用现成的就不采集，能近做就不远行。

## 1. 决策树（按顺序）

```
重生
├─ 0. 安全检查
│   ├─ 附近有敌对/HP太低/饥饿太低 → 先保命（本能/守家/等回复）
│   └─ 安全 ↓
├─ 1. 身上/重生点是否有现成武器？
│   ├─ 有 → 装备（equip_best），转"工具"目标
│   └─ 无 ↓
├─ 2. 白天？
│   ├─ 是 ↓
│   │   ├─ 2a. 死亡点可恢复？（距离/维度/时间/掉落是否还在）
│   │   │   ├─ 是 → 去死亡点捡装备（武器优先；工具也算）
│   │   │   └─ 否 ↓
│   │   ├─ 2b. 附近（重生点/家/已知箱子）有武器或材料？
│   │   │   ├─ 有武器 → 取/装备
│   │   │   ├─ 有材料 → 就地做（2×2 做桌→3×3 做武器）
│   │   │   └─ 都没有 ↓
│   │   ├─ 2c. 附近有树/可采材料且安全？
│   │   │   ├─ 是 → 现采 → **就地做**（做工作台→武器→工具）
│   │   │   └─ 否 → 去家/已知资源点（评估路程与危险）
│   │   └─ 2d. 都不行 → 上报/等主人补给
│   └─ 否（夜晚）↓
│       ├─ 3a. 在基地/重生点且安全 + 有材料/箱子 → 就地做（不出去）
│       ├─ 3b. 基地远但不危险 + 有光/武器 → 考虑回家（否则守）
│       ├─ 3c. 附近有床 → 睡到天亮再按白天流程
│       └─ 3d. 都不行 → 守到天亮/上报，**不出去捡死亡点**
└─ 武器到手后，重复 1~3 的流程处理"工具"
```

## 2. 需要判断的情况（你列的 + 补缺）

| # | 情况 | 影响 |
|---|---|---|
| 1 | 白天 / 夜晚 / 黄昏（离天黑多久） | 夜晚禁止远行/去死亡点；黄昏要评估是否来得及 |
| 2 | 重生点是否安全（敌对/光照/HP/饥饿） | 不安全先保命，不进入装备流程 |
| 3 | 死亡点是否可恢复 | 距离、维度、是否水下/岩浆/虚空、掉落是否已消失 |
| 4 | **死亡掉落物消失时间**（~5 分钟） | 距离远/天黑就先放弃，改合成 |
| 5 | 死亡点是否被别的生物/玩家捡走 | 拿不到就转合成 |
| 6 | 重生点/基地附近**有没有箱子** | 有箱子先 `scan_container` 查内容：现成武器 > 材料 > 空 |
| 7 | 箱子/背包里有没有**现成武器**（含 mod 武器） | 有就装备，跳过长流程 |
| 8 | 有没有**现成工具**（镐/斧） | 工具目标可跳过；斧可临时当武器 |
| 9 | 有没有**工作台**（附近/家里） | 2×2 只能做桌/木板/棍；剑/镐/斧必须 3×3 工作台 |
| 10 | 有没有**材料**（原木/木板/木棍） | 有材料→就地做；没材料→现采 |
| 11 | 附近**有没有树/石头**（采集合规） | 决定"现采"是否可行；石头需要先有木镐（鸡生蛋） |
| 12 | **就地做 vs 回家做**：路程、危险、时间、工作台位置 | 近且安全→就地；远/危险→回家；夜里尽量不跨区 |
| 13 | 回家路线是否安全（敌对/地形/水/悬崖） | 路线危险就守/等天亮 |
| 14 | 有没有**床**（重生点/基地） | 夜里可睡到天亮，绕开夜行 |
| 15 | 主人是否在线/附近，能否补给 | 主人在→可求援；主人远→自理 |
| 16 | 最近是否**连续死亡**（死循环风险） | 连续死→延后恢复/换区域/回家，不重复去同一地点 |
| 17 | HP/饥饿是否够支撑采集/合成 | 不够先吃/等回血（当前食物暂不优先，但极端低血仍要处理） |
| 18 | 天气/雷暴/光照 | 影响夜行和露天合成风险 |
| 19 | 装备**耐久/品质**（mod 装备） | numen 不暴露耐久/NBT，拿不到就只能按"有/无"处理（图鉴以后补） |
| 20 | 工具/武器的**层级**（木→石→铁） | 木镐是石工具的前置；武器可先用木剑/斧过渡 |
| 21 | 死亡点与家的**相对距离** | 近死亡点优先捡；家更近且安全则回家 |
| 22 | 背包里是否还有**残留物**（重生不一定全空） | 有就不采/不做，直接用 |
| 23 | 是否需要**先做工作台**（材料够但没台） | 2×2 做桌→放置→3×3 |
| 24 | 合成的**安全位置**（露天/封闭、是否会被怪打断） | 夜里/危险区就地做要有掩体，否则回家 |
| 25 | 死亡点是否在**其他维度**（下界/末地） | 不能直接走过去，先回家/找传送门，通常改合成 |

## 3. 缺失的数据/能力（当前实现没有）

| 缺什么 | 影响 | 归属 |
|---|---|---|
| 死亡掉落**剩余时间/是否还在** | 无法判断值不值得跑 | 需要追踪死亡时间 + 掉落状态（numen 不直接给，可按时间估算） |
| 容器内容查询（重生点/家/沿途箱子） | 不知道有没有现成武器/材料 | 缺战术 `scan_container` |
| 附近资源扫描（树/石头/工作台/床） | 不知道"现采/就地做"是否可行 | 缺 `locate_station` 泛化 + `scan_blocks` 战术 |
| 路径危险评估 | 回家/去死亡点可能送死 | 缺导航风险层 |
| 死亡点可达性（水/岩浆/虚空/维度） | 可能白跑 | 需要地形/维度检查 |
| 工作台/2×2 vs 3×3 判断 | 没有台做不了剑镐 | 需要 `craft_batch` 前置检查 + `place_one` |
| 现成武器/工具识别（含 mod） | 不知道箱子里的是不是装备 | 需要图鉴/角色标签 |
| 连续死亡记录 | 防死循环 | 需要需求板冷却/死亡计数 |

## 4. 实现拆分建议

**战略包 `secure_gear`（L3，死后触发）** 拆成子战略，按条件选择：
1. `recover_death_drops`（L2）——白天 + 死亡点可恢复；
2. `use_spawn_cache`（L2）——重生点/基地箱子有武器/材料；
3. `craft_from_materials`（L2）——材料在背包/箱子，附近有工作台或能放台；
4. `gather_then_craft`（L3）——需要现采（木→桌→武器→工具）；
5. `return_home_craft`（L2）——回家做；
6. `wait_for_day`（L2）——夜里不安全时守/睡/等。

**需要的战术（按优先级）**：
1. `scan_container`（只读查箱子内容）
2. `find_block` 泛化（树/工作台/床/石头）
3. `place_one`（工作台）
4. `dig_cluster`（砍树/挖石）
5. `craft_batch`（已有）+ `equip_best`（已有）
6. `sleep_once`（夜里跳过）
7. `travel_to`（分片移动 + 风险中止）

## 5. 简化版 v1（先跑通）

先不做全部条件，v1 只覆盖：
- 白天 + 安全 + 死亡点距离≤64 且死亡<4分钟 → `recover_death_drops`；
- 否则：重生点/基地箱子有现成武器 → 取；有材料+工作台 → 做；
- 否则：附近有树且安全 → 砍→就地做桌→木剑→木镐/斧；
- 夜里 → 守/等天亮，不出去；
- 连续死亡 ≥2 → 延后 5 分钟/换策略。

### 6.2 合成 fallback 已实现（2026-11-08 22:5x）

- `secure_gear` 在"死亡点捡不到/没有死亡点/去不了"时，走合成 fallback：
  1. 找树（`#minecraft:logs`）→ `travel_to` → `dig_cluster` 砍 6 个 → `collect_drops`；
  2. 用 `query_craftable` 动态找木板/木棍/工作台配方（适配不同木头）；
  3. `craft_batch` 做木板/木棍/工作台 → `place_one` 放桌 → `open_station`；
  4. 做木剑（需要 `get_weapon` 时）/木镐+木斧（`get_tools` 时）→ `equip_best`。
- 预算：secure_gear maxTactics 24 / maxSeconds 90。
- 测试：战略 **21/21**；战术 97/97、需求 31/31、执行策略 31/31、回放 20/20（182 断言）。
- 实机：当前夜里，trace 显示 `secure_gear wait（夜里不出去）`；白天安全时会走恢复/合成。

### 6.3 箱子优先已实现（2026-11-08 22:5x）

`secure_gear` 在去死亡点失败/没死亡点/死亡点没捡到后，会先：
1. `locate_station(minecraft:chest, radius 24)` → `travel_to` → `scan_container`；
2. 箱子里有现成武器/工具 → `fetch_batch` → `equip_best`（不再砍树）；
3. 没有装备但有原木/木板/木棍/工作台 → 取材料，再走合成 fallback；
4. 都没有 → 找树/就地合成。

测试：战略 **22/22**；战术 97/97、需求 31/31、执行策略 31/31、回放 20/20（182 断言）。

### 6.4 夜间处置已实现：night_hold（2026-11-08 23:0x）

- 需求 `night_chase` 现在映射到 `strategy.night_hold`（不再误用 secure_gear）；
- 行为：
  - 白天/无怪 → `already_safe`；
  - 夜里 + 离家 >16 → `travel_to` 回家（不继续跑远）；
  - 已在家附近 → `hold_near_home`（就地守，让本能防御/等天亮）；
  - 回家路线失败 → `return_failed`，就地守；
  - 没有家记录 → `no_home`（上报）。
- 测试：战略 **27/27**；战术 97/97、需求 31/31、执行策略 31/31、回放 20/20（182 断言）。
- 说明：树不能撤销本能 FleeChain；能做的只是"本能结束后把同伴往回带/就近守"，避免越跑越远。
