# 121. A1–A5 分层调度圆桌共识

> 2026-11-11。玩家代表 + 项目总控 + 点子王 + 行为学家。  
> 议题：玩家提出的 A1–A5 分层调度（失败下滑/成功上浮/反射插入）与当前调度器的对账。

## 1. 共识

```text
方向对，但模型 80% 是对现有链的规范化。
真正新增的是“严格父子弹栈 + 失败下滑/成功上浮”，这部分属于 P2。
```

当前链：

```text
needs/drives（条件）
→ strategy（扁平选择）
→ plan 固定配方步骤
→ tactic
→ atom/skill/reflex
```

## 2. 映射

| 玩家模型 | 当前 | 缺口 |
|---|---|---|
| A1 求生/宏观 | needs/drives + 硬门 | needs 是条件，不是可上报的父目标 |
| A2 领域/里程碑 | 扁平 strategy | **缺失** |
| A3 细分里程碑 | 固定 recipe steps | **缺失** |
| A4 执行 | tactic/plan cursor | 基本对应 |
| A5 原子/反射 | atom/reflex | 对应，反射插入已有 |

最大缺口：

```text
A2/A3 没有“结果谓词 + 父子关系 + 结果上报”。
plan 完成 ≠ milestone 达成。
```

## 3. 玩家代表

会更像人，但前提是**意图可见**，不是层数多：

```text
在一个目标上连续干几分钟
被打断后回到原目标
失败时看得出“试了→退了→换低一级办法”
完成后有可读停顿再上浮
```

最担心：

```text
从“跳”变“死磕”
救火看不到
栈本身抖动
层级更黑箱
```

验收：

```text
任意时刻能说清：当前目标、上一级、为什么现在做
5 分钟内不翻日志能看到一次完整下滑/上浮
```

## 4. 行为学家

```text
层级只给“方向”，不自动产生注意力。
```

注意力必须独立补：

```text
选择性瓶颈
驻留/持续
显著性打断
抑制回头/习惯化
```

失败下滑必须约束：

```text
单次失败不降级，连续失败达阈值才降
恢复记忆优先于重新规划
上浮先看同级兄弟，不立刻换领域
下滑目标冷却，上浮领域抑制
同时只有一个活跃 A3
反射结束回挂起点
```

判负：

```text
单次失败导致 A2/A3 降级 = 0
同一天上浮后开新领域次数 ≤ 上限
```

## 5. 点子王

最小改造不要先搭五层：

```text
1. A1 并入 needs/gate
2. A2/A3 先合成 milestone 层（结果谓词）
3. 加 parentId + 失败上报
4. plan/strategy 失败先给父层“换方法”机会
5. 上浮只看结果谓词 + evidence，不看 plan 跑完
6. 动态里程碑用 GoalStore，单活跃
```

风险：

```text
层间乒乓
同一根因跨层重复计数
plan 冒充 milestone
```

判负：

```text
同一根因在 ≥2 层重复尝试/计数
plan 完成但谓词未达成却上浮
```

## 6. 项目总控

```text
结果语义（milestone/失败三分）：P0/P1
严格分层 + 滑动栈 + 动态里程碑列表：P2
```

排期：

```text
P0：不改 Arbiter，只收口状态机/门控/谓词
P1：只预留接口（parentId/结果谓词/失败原因）
P2：才实现严格分层与滑动栈
```

红线：

```text
P0 出线前，不允许先改调度主干再跑 Day1；
分层调度只允许接口，不允许实现。
```

## 7. 最终结论

```text
A1–A5 方向保留，作为 P2 目标架构；
P0 只做 milestone 结果语义 + 失败/证据上报；
P1 预留父子/结果谓词接口；
P2 再实现滑动栈与动态里程碑。
```

```text
不要用架构重构替代 P0 能力验证。
```
