# 42. 学习：离线轨迹归纳 + 窄学习接口

> 2026-11-09。学习拆两件事：
> - **离线学习**：DSH 采轨迹 → 归纳战略包/表（后置，不在树内）；
> - **窄学习**：树内只做策略成败统计 → 小幅优先级反馈（先做接口）。

## 1. 离线学习（后置）

```text
DSH/LLM 直连 numen MCP（沙盒存档）
  → 跑长任务（钓鱼/铁器时代）
  → 记录结构化轨迹
  → 离线分段/标注/归纳
  → 回放验证
  → 战略包/表入库
```

### 日志不要只存“明文思考”

建议 JSONL：

```json
{
  "t": "...",
  "goal": "iron_pickaxe",
  "phase": "mine_iron",
  "observation": { "pos": "...", "hp": 20, "inventory": [], "dark": false },
  "thought": "...",
  "tool": "numen.move.to",
  "args": {},
  "result": { "ok": true },
  "outcome": "progress|success|fail|damage|waste"
}
```

关键：状态快照、动作、结果、阶段标签、最终成败、成本/受伤。

### 归纳管线

1. 采集；
2. 分段（目标/阶段/停顿/失败）；
3. 标注成功/失败/成本；
4. 归纳候选 tactic/strategy/profile；
5. 回放验证；
6. 入库；
7. 线上观察。

### 风险

- 轨迹质量差 → 学坏习惯；
- 绕过树的 guardrail；
- 过拟合单个存档；
- 没有因果信用分配。

所以：沙盒 + 结构化日志 + 验证 + 人工/AI 审查。

## 2. 窄学习接口（已落地）

`src/learning.mjs`：

```js
createLearningState()
recordStrategyOutcome(state, { strategyId, ok, kind, ms, now })
learningBonus(state, strategyId)   // -5..+5，样本<3 不生效
describeLearning(state)
```

- 每个战略记录 attempts/success/fail/avgMs/EWMA/recent；
- EWMA 成功率 → 小幅度 priority 加成/惩罚；
- 已接入调度候选分；
- `tree_status detail.learning` 可观测。

这属于“自我调整策略压力”的一部分，但不是自学战略。

## 3. 边界

- 不做在线 RL；
- 不让树自己改代码/发明战略；
- 不让学习覆盖硬安全/反射；
- 学习只调权重，且有上限；
- 成功定义要可靠，否则会奖励错误行为。
