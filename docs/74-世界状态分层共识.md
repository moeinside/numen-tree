# 74. 世界状态分层共识（修订 72）

> 2026-11-10。玩家澄清“作弊扫描是给树工具做世界记忆”。六位顾问讨论后，形成对 docs/72 的**正式修订**。  
> 结论：**允许树级 WorldHints（不是 Truth）；动作前置仍只认具身事实。**

## 1. 共识

- 之前“死红线”把两件事混了：
  1. 同伴的具身感知；
  2. 树的世界记忆/规划后端。
- 前者必须守住；后者可以持有全局提示。
- 但不能把“树知道”变成“同伴看见”。

## 2. 命名

不叫 `WorldTruth`，改叫 **`WorldHints`**：

- 它不是真值承诺；
- 是带来源、时间、版本、置信度的候选/提示；
- 会过期，会错，必须现场验证。

## 3. 分层

```text
L0 Numen 自报（hp/ hunger/ hands/ inventory）
L1 CompanionKnowledge（触手+numen 现场观测 / postcheck）
L2 WorldHints（树级扫描/事件/记忆，source=server-scan）
L3 Memory（places/worldmem/SpatialMemory）
```

硬规则：

- **动作前置只认 L0/L1**；
- L2/L3 只能产生 `explore` / `verify` / `recheck`；
- 目标参数禁止携带未发现实体的属性（内容、数量、精确坐标）；
- L2/L3 不得写入 `CompanionFacts`；
- 冲突以 L1 现场观测为准；
- 容器内容不扫/不用；怪物位置不进运行时战斗/绕行，只作区域风险提示。

## 4. 允许 / 禁止

### 允许

- 探索方向/候选区域；
- 已探索地形记忆；
- 资源“方向级”提示；
- 异常/变化检测；
- 审计/离线对照；
- 多同伴未来共享（后置）。

### 禁止

- 直接生成“取/挖/开/打”未发现目标；
- 精确坐标/容器内容/怪物位置进入运行时决策；
- 把 WorldHints 写成 Fact；
- 用 WorldHints 满足动作前置；
- 用 WorldHints 作为 Day1 通过理由；
- 周期全量扫描（TPS/截断/过期）。

## 5. 动态世界刷新

不是“黎明一次全量扫描”就够：

- 事件优先（容器开关、方块变化、区块加载）；
- 惰性校验（使用前 L1）；
- 兴趣区低频巡检；
- 周期快照只作兜底；
- “全局”= 已加载区，不是全图；
- 必须带 observed_at/version/TTL。

## 6. P0 范围

- **默认关闭 WorldHints**；
- 只做离线 oracle（审计对照，不进生产配置）；
- Day1 以纯具身版本判负；
- trace 出现 WorldHints 泄漏即判负；
- 同时出 oracle 与非 oracle 两份报告，只认非 oracle；
- 多同伴共享后置。

## 7. 北极星不变量 8 改写

旧：禁止全知。

新：

- **8a**：动作前置只认现场观测/交互/postcheck；
- **8b**：树可持有 WorldHints，但只能产出“待验证假设/探索方向”，必须带来源与时效，不得以任何路径进入动作可行性或“直接获取”目标；
- **8c**：泄漏即判负；Day1 不带 WorldHints 跑。

## 8. 验收（泄漏判负）

1. 未发现箱子/树只存在于 WorldHints，目标若变成“去拿它” → 判负；
2. 动作目标无法追溯到此前 L1 known 事件 → 判负；
3. WorldHints 与现场冲突仍按 hint 执行 → 判负；
4. Day1 trace 中 WorldHints 调用数必须 = 0；
5. 生产配置快照证明开关 off；
6. 有 oracle 对照报告，但出线只认非 oracle。

## 9. 六位结论

| 角色 | 结论 | 关键条件 |
|---|---|---|
| 总控 | 有条件同意 | 不变量 8 改成“禁止全知进入行动链” |
| 产品经理 | 有条件同意 | P0 off；泄漏负样本+溯源审计 |
| 行为学家 | 有条件同意 | WorldHints 只是“传闻”，目标禁带未发现属性 |
| MC 专家 | 有条件同意 | 已加载区；容器内容不扫；事件+惰性刷新 |
| 点子王 | 有条件同意 | 改名 WorldHints；四道机制隔离；P0 只做 oracle |
| 玩家代表 | 有条件同意 | 摘除对照跑；目标动词限 explore/verify；修订需 Lead 确认 |

## 10. Lead 决议

- **接受对 docs/72 的修订**；
- 命名改为 **WorldHints**；
- P0 默认关闭，只做离线 oracle；
- 动作前置只认 L0/L1；
- 运行时启用 WorldHints 是 P1+ 的独立 gate，需要先通过泄漏负样本；
- 多同伴共享后置。

## 11. 一句话

> **树可以有世界记忆/提示，但只有同伴亲自看见的东西才能驱动动作；WorldHints 能说“去哪看”，不能替同伴说“那有什么、直接去拿”。**
