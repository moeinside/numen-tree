> 2026-11-11。点子王 × MC 专家。  
> 用户明确：允许新加 mod，允许覆盖面完全的游戏内作弊调试工具。

## 1. 总体分层

```text
tentacle        具身感知：FOV/LOS/16格/只给自己 —— 保持不动
groundtruth     全能观测 + 受控写（127.0.0.1:8771，dev-only）—— 新增
numen-devtools  原版命令 portal（8770）—— 降级为命令兜底，不再扩展
```

边界：

```text
决策只能用 tentacle/numen

```

## 2. groundtruth 服务

### 时钟

```text
gameTick / gameTime / dayTime / isDay / weather
freeze / step(n) / set(gameTime)
```

所有记录双时间戳：gameTick 权威，wall 辅助。

### 事件流

append-only JSONL / HTTP 游标：

```text
GET /events?since=<seq>
```

事件 schema：

```json
{"seq":1,"gameTick":...,"wall":...,"worldId":"...","dim":"...",
 "type":"block_break|block_place|entity_join|entity_leave|entity_death|
         damage|container_open|container_close|item_pickup|item_drop|
         pos|time|weather|chunk_load",
 "actor":"...","pos":{...},"payload":{...},"source":"groundtruth"}
```

### 快照

```text
动作前后区域快照
+ 周期快照
+ 方块增量 / 区域 hash
+ snapshotSeq 单调
动作窗口 = [seqBefore, seqAfter]
```

### 查询

```text
blockAt(pos) / scanBox / entitiesIn / lightAt / canSee
routeProbe(from,to)  // 独立对照 route.plan
```

### 作弊写入（独立 POST，全部审计）

```text
setblock/fill/clone（体积上限）
summon 任意 NBT
damage/heal（自己实现，绕过 damage root 限制）
setHealth/setFoodLevel/setSaturation
teleportTo
kill(tag)  // entity.discard，绕过 Invulnerable
freeze/step/set time
snapshot/restore/hash
```

UI 不做；本地只读 HTML 读 JSON 即可。

## 3. 快照 / 回滚 / 清理 / 冻结

```text
快照：save-off → save-all flush → 复制 saves/<world> → save-on
      目录级 sha256（level.dat + region/ + data/）
回滚：停机替换目录再起；mod 只做请求停机 + 恢复标记
清理：kill(tag) 或 teleportToPrison(tag, farPos)
冻结：每 tick 复位 dayTime；审计标 clock_frozen
```

冻结副作用：作物/熔炉/刷怪计时停止；冻结 run 不作验收证据。

## 4. 最小可交付顺序

```text
1. 时钟 + 事件游标
2. 动作前后快照 + 区域 hash/diff
3. 查询 blockAt/scanBox/entitiesIn/lightAt
4. 精确状态注入 hp/food + kill(tag)/tp(tag)
5. 快照/回滚编排 + hash
6. 审计强制
```

之后：容器读取、可达性探测、完整作弊面、存档分支。

## 6. 验收

30 秒真实动作序列（挖/放/捡/受伤/夜转）：

```text
事件流可独立复算 worldDelta，且与快照 hash 一致
冻结期间 gameTick 不前进，前后快照可配对
回滚后世界 hash 回到回滚点
诊断工具仅凭事件流可判出一次 progressing 和一次 stalled
```

判负：

```text
无法从事件流+快照独立复算 worldDelta
作弊写入进入 Track A 证据链（未标 assisted/混入 trace/被当能力）
groundtruth 数据进入 FactStore/候选/目标/precondition
clock_frozen 的 run 被当验收证据
```
