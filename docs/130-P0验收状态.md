## 6. watchdog 真实验收结论

MC 专家判定：

```text
真实世界构造不出“active + 长期无进展”且非合法 wait 的状态。
世界侧 GM 只能改世界，改不了树内部：
paused / actionLock / pendingInterrupt / exec.mode+cooldown。
任何造法先落到这些闸，plan 会被 suspend，而不是 active。
```

真实能构造的 active 无进展，恰好是合法 wait。  
watchdog 若对合法 wait 触发，证明的是误报，不是有效。

结论：

```text
真实世界不可验 watchdog 缺陷。
要么接受契约夹具 cap_dispatch_stall；
要么用测试态 stub 注入（只测试，不进产品）。
```

测试态注入需要压平：

```text
paused/actionLock/pendingInterrupt/exec mode/cooldown
hp/hunger/hostile/inWater/lastReflex
+ stub tactic + 可控时钟
```
