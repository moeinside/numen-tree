# 89. 树主任务复审结论（工具就位假设）

> 2026-11-10。六位顾问复审 docs/88 后的 Lead 收敛。  
> 结论：架构方向继续有效；P0-0b 优先级不变；Day1 只补“环境前提 + 纯度谓词”，不改行为门槛。

## 1. 审批状态（准确表述）

- **架构方向**：有条件通过，可继续 P0-0b；
- **Day1 规格**：docs/78 有条件批准，现补 docs/89 两条前提；
- **P0-0a**：代码/测试已有；
- **P0-0b**：未完成；
- **开发工具**：按“已就位”作参考，但 GM 未交付；不改变 Track A。

## 2. 共识：架构不调整

- 工具是旁支观测器，不接树运行时；
- 不为工具加兜底/钩子/求助通道；
- 树仍按“感知→Facts→需求/注意→milestone→SOP→执行→失败三分”；
- 工具就位不是里程碑，不插队；
- Track A 仍是唯一出线证据：无 LLM、无 GM、无 WorldHints。

## 3. 必须补的两条 Day1 前提

### 3.1 M4 夜间“假绿”前提

MC 专家指出：

- 1.21 敌对生物只在距玩家 **24 格外**刷出；
- 距最近玩家 **128 格外**消失；
- 玩家在 bigwhale 附近时，夜间几乎不刷怪。

因此：

> **M4 `night_no_damage` 只有在玩家 ≥64 格或离线时才算数；否则该次 run 的夜间项作废。**

这是环境前提，不是提高行为门槛。

### 3.2 Track A 纯度谓词

Track A run 必须同时满足：

- `mode` 非 DEV，无 dev lease；
- 8770 未监听；
- trace 中无 `reference-pilot` / `assisted` / `gm` / `cheat` 记录；
- 无 WorldHints 泄漏；
- 工具日志/试驾员记录不进入 A 的证据链；
- 审计对工具通道**加载期硬拒绝**，不是事后过滤。

## 4. 工具能做什么/不能做什么

### 可借

- 夹具搭建、快照/回滚；
- 机制事实补测（生肉可吃性、avoid 全值表、scan 上限、夜间视距、category 抽样、events 是否吃槽）；
- 失败复现、负样本注入；
- 假设生成（“同一场景怎么做”）。

### 不可借

- 行为规范（优先级/节律/阈值/动作序列）；
- 能力本体（入口策略、结果语义、失败归因）；
- 唯一验收证据；
- 学习正样本；
- “未知下探索”的建设压力。

判据：

> **涉及“选择”的必须树跑；涉及“世界是否这样”的可由工具佐证。**

## 5. P0-0b 顺序（收敛）

1. 修 `avoid` cell type（树的导航 bug）；
2. 结果型 GoalStore / milestone 语义（先改 schema，避免 from_zero 又写成 plan）；
3. 食物/低血硬门；
4. `from_zero` 最小链（木→台→木工具尝试→夜间安全）；
5. 默认起始倾向 / 入口策略；
6. 纯度谓词 + M4 环境前提；
7. 冻结 Day1，Track A 盲跑（玩家 ≥64 格或离线、同快照起跑）；
8. 达标才谈两夜/多同伴。

## 6. 明确不做

- 不为工具加运行时钩子；
- 不用试驾员/GM 补链或补证据；
- 不把 assisted/参考 run 当学习正样本；
- 不因工具就位放宽 Day1；
- 不修工具代码（Lead 只碰树；旁支交独立子体）；
- 不提前做 H2/H3。

## 7. 最大风险

1. **工具就位被读成能力就位**（“试驾员跑通”≠“树跑通”）；
2. **注意力漂移**：反复跑 pilot 而不写谓词/硬门；
3. **GM 依赖传导**：按“有 GM 的世界”设计树；
4. **世界基线污染**：A/B 同存档、资源被消耗；
5. **设计变更不绑 A trace**：谓词/入口改动没有真实失败依据。

## 8. 六位结论

| 角色 | 结论 | 关键条件 |
|---|---|---|
| 总控 | 有条件同意 | 工具只改“发现问题”的速度；不接运行时；不是里程碑 |
| 产品经理 | 有条件同意 | Day1 谓词不动；只加纯度谓词；工具证据零进入 |
| 行为学家 | 有条件同意 | 工具只改缺口清单；禁借优先级/节律/阈值/动作序列 |
| MC 专家 | 有条件同意 | M4 假绿；玩家≥64 格/离线；先食物/低血硬门 |
| 点子王 | 有条件同意 | 先改结果型 GoalStore；设计变更绑 A 失败 trace |
| 玩家代表 | 有条件同意 | 区分“树跑通”和“试驾员跑通”；验收零改动 |

## 9. 一句话

> **工具让我们更快看见问题，但不替树长能力；P0-0b 按原架构继续，Day1 只补“夜间无玩家刷怪抑制”和“A 纯度”两个前提。**
