### 7. GoalProfile 自动续跑（最小）

- 启动时只把 `status=active` 的 milestone 放进 `pendingGoalResume`；
- 第一轮观测完成后、需求板之前执行恢复；
- 先跑 `resumeDecision` 世界谓词：
  - 已完成 → 标 done，不重放；
  - 未完成且有验收谓词 → 重开对应 SOP；
  - 未知 recipe → 不自动重开；
- 维度不符 → 不恢复；
- 实机受控验证：
  - `goal_resume_start gather_wood 从 milestone 恢复 SOP`
  - 计划确实重新启动，而不是从 plan cursor 硬恢复。
