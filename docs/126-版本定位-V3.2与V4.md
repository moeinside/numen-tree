# 126. 版本定位：V3.2 倾向种子 / V4 多同伴分工

> 2026-11-11。点子王 + 行为学家 + 项目总控 + 玩家代表。  
> 议题：新建同伴固定倾向种子 + 能力匹配 + 共享需求领取，算 V4 还是 V2.1？

## 1. 结论

```text
不是 V2.1。
拆成两个版本：
V3.2 = 单同伴倾向种子（小特性/实验）
V4   = 多同伴共享需求领取与分工（独立支线）
```

V4 不塞进 V3.2；V2.1 不复用（V2 是排班表，不是这条线）。

## 2. V3.2：倾向种子

```text
新建同伴生成固定倾向向量
只做同分/近分时的权重偏置
不改仲裁结构
不进入 eligibility
硬安全/强需求可覆盖
必须持久化、可复现
```

用途：

```text
同一条件下，同伴更愿意先做哪类事
形成行为一致性
不是职业锁定
```

## 3. V4：多同伴分工

```text
共享需求池
原子领取/owner/超时/冲突解决
能力匹配
比较优势
结果反馈与轮换
```

它是新的协作层，不是单同伴调度的开关。

## 4. 两个不能混

```text
倾向种子 = 个体差异
共享领取 = 分布式协作
```

混在一起会把“多同伴还没设计”的东西当成一个按钮加进来。

## 5. 排期

```text
P0：无关，红线；不允许做多同伴
P1：只允许预留 role/倾向字段，不进入行为主排序
P2：学习/拟人，仍以单同伴为主
P3/P4：多同伴协作与自然分工
```

红线：

```text
多同伴/共享领取不得早于 P0/P1 出线；
倾向种子若在 P1 前进入行为选择，视为范围漂移。
```

## 6. 风险

```text
种子硬化成职业锁定
单同伴看不出“性格”，只看出随机
种子不可复现/重启丢失
共享领取双 owner/重复领取/超时未释放
共享信息过期造成假分工
```

## 7. 验收

### V3.2

```text
同一 seed 跑两次新世界，前 10 分钟偏好方向可复现
玩家只从行为能反推“它偏什么”
硬安全/强需求能覆盖倾向
重启后 seed 不丢
```

### V4

```text
同一时刻两名同伴持有同一需求/同一目标的次数 = 0
领取有 owner、超时、释放
冲突有确定裁决
```

判负：

```text
双 owner / 重复领取
seed 不可复现
硬安全被倾向压过
多同伴早于 P0/P1 出线
```

## 8. 一句话

```text
倾向种子是“性格”，V3.2 小特性；
共享领取是“分工”，V4 独立支线；
现在只登记，不实现。
```
