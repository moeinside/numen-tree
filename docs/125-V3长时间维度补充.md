# 125. V3.1：长时间维度补充

> 2026-11-11。点子王 × 行为学家。  
> 提醒：同伴行为不能只看“当前任务完成与否”，要看跨段、跨天的连续性、恢复、进度和漂移。

## 1. 结论

```text
V3 仍推荐，但必须加长期层。
不加：V3 只是“每天重启的日计划”。
加完：V3.1。
P0 不动。
```

## 2. V3 在长时间维度的问题

```text
机会吞噬主线：每次机会都对，几天后主线没动
再入线索过期：三天前的砍树点已变，硬恢复=重复失败
日终重排=每天重启：进展不累积
单焦点无节奏：疲劳/风险暴露累积
议程被新债挤出：跨天忘债
重做算进展：反复开新头也能显示在推进
```

## 3. 必须补的长期机制

### 债本

```text
未还义务跨天结转
createdDay / 连续未还次数 / 证据 / staleDays
超 N 天不得静默消失
→ 降级/升级/求助/显式放弃
```

### 进展账

```text
每个长线记不可逆进展点
predicate + evidence + snapshotSeq
只增不减
重做不计分
```

### 配额

```text
主线 / 机会 / 恢复
例如 70 / 20 / 10
机会不能无限侵蚀主线
```

### 日结 / 晨间复盘

```text
天亮/天黑边界强制盘点
未完成项、过期项、放弃理由
次日晨读结构化字段
不存 plan cursor
```

### 再入重验

```text
恢复前重验线索前提
地点 + 名称/物品 + 日结回顾三路冗余
失效则重规划
```

### aging + 显式放弃

```text
长期无进展 → 降级
过期 deadline → backlog
不许无限挂着
```

## 4. 长时间验收

```text
恢复保真率：打断后 60s 内回原议程
债务遗漏率 = 0
每 2 天 ≥1 个不可逆进展点
主线时间占比 ≥ 配额
机会超配额即负
开新头/完成 >1 即“反复开新头”
跨天再入准确率：次日首焦点引用昨日未完成项
重做率：已完成项被再次推进 = 0
```

判负：

```text
2 天窗口 0 进展点
或债务遗漏
或机会长期超配额
或重做算进展
```

## 5. 结构不变，补长期环

```text
V3：议程 + 焦点 + 再入线索 + 机会窗口 + 空焦点基线
V3.1 = V3 + 债本 + 进展账 + 配额 + 日结/晨间复盘
```

不是换成 V2 班次表，也不是 V1 层级栈。

## 6. 排期

```text
P0：不动
P1：债本 + 日结 + 配额（薄）
P2：进展账、再入重验、aging、完整长期环
```

## 7. 一句话

```text
单日看“做没做完”；
多日看“欠的债有没有丢、主线有没有动、机会有没有吃掉主线”。
```
