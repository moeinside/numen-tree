# 117. 分时段行为模式规划（共识）

> 2026-11-11。行为学家 × MC 专家两轮红蓝对抗后定稿。  
> 原则：不做“钟表驱动的状态机”；用时间段约束候选生成与行为重点，真人观感优先，机制可执行。

## 0. 基础事实

```text
1 天 = 24000 tick = 20 min 真实时间
1000 tick = 50 s
dusk 从 11000 起算（项目自定，100 s 缓冲；vanilla 12000 只有 50 s）
夜间安全半径约 16 格
```

## 1. 时间段表（最终）

| 段 | 边界 tick | 主目标 | 允许候选 | 基线行为 | 玩家互动 |
|---|---|---|---|---|---|
| 黎明尾/清晨前 | 23000–24000 | 安全确认、等天亮 | `eat` `scan_ground` 清点、靠近玩家 | 看天、起身、不提前远行 | 等玩家醒，不打扰 |
| 清晨 | 0–1000 | 确认方位、进食、侦察残留威胁 | `eat` `equip` `scan_ground` `collect_items`(小) | 观察→敌>0 退回避难 | 报“我醒了”，等首个指令 |
| 上午前段 | 1000–3000 | 轻量启动、就近采集 | 观测/盘点/短采集/整理 | 走向工作区，不空转 | 打招呼、不挡路 |
| 上午主段 | 3000–5000 | 当日主 milestone 第一段 | `mine_nearby` `craft` `find_table` `place_block` | 主目标阻塞→次目标 | 玩家示意先收尾原子再响应 |
| 正午 | 5000–7000 | 状态检查、补短板 | 进食（仅饥饿）/盘点/工具检查/短整理 | 坐、整理、饿才吃 | 玩家休息则同步休整 |
| 下午 | 7000–11000 | 收尾 + 首次 `readiness.night` | 中短链/备料/建造/修补/`return_home` | 缺什么补什么 | 段末短报进度 |
| 黄昏 | 11000–13000 | 只做**即时类动作**，可串行 | `travel_to`(≤16) / `place_block`封口 / `eat` | 无候选→就地 1×2 洞封口 | 同向回家，到家打招呼 |
| 入夜 | 13000–18000 | 不受伤、吃饱、建立安全态 | `eat` `seal` `scan_ground` `retreat` `sleep`(有床) | 吃→封口→有上限 wait | 玩家外出不擅随，留家并说明 |
| 深夜 | 18000–23000 | 保命、低耗恢复 | `eat` `wait` `seal` `retreat` 低频守护 | **低警戒恢复 + 偶尔查看玩家** | 玩家危险才靠近/唤醒 |

## 2. 关键修正

- **正午不是吃饭段**：进食只由饥饿驱动；正午只是状态检查点。
- **深夜不是全程警戒**：允许低警戒恢复/就地休息，避免踱步或站桩。
- **黄昏只做即时类动作**：遮蔽/回锚点/吃，可串行 2–3 项，总预算 ≤100s；每项完成后重判剩余时间；不开新采集链。
- **黄昏删“点火把”必须项**：有现成可放置光源才算可选，不排长链。
- **黎明边界**：23000–24000 与 0–1000 行为策略几乎相同；实现可保留两个 label，但不要把它当两个可自由切换的段。

## 3. 段内规则

```text
段内禁止换“生产目标”
允许安全升级 / 停止 / abandon + reason
换生产目标只在段边界或硬信号
```

原因：抢占是事件驱动、只在原子边界生效；字面“段内绝不换”会卡死危险响应。

### 3.1 plan 绑定段（点子王 × MC 共识）

目标生成时写入：

```text
segId        生成段
deadlineSeg  最晚完成段
```

- `deadlineSeg` 由 plan 类型定：采集/合成类 = `afternoon`，回家/封口类 = `any`；
- 每个**原子边界**比较 `currentSeg` 与 `deadlineSeg`；
- 超期且下一步属于当前段禁止集 → `abandon/wait` + reason；
- 否则继续，**不重排、不重启**；
- 段边界只拦“新目标生成”，**不强制挂起正在跑的 plan**；
- 跨段 plan 到点不挂起，只在原子边界检查下一步是否越界。

## 4. 候选生成

```text
先按段过滤，再按窗口/暴露过滤
长链不进夜间候选，而不是生成后挂起
```

夜间/黄昏禁止：

```text
explore / forage / seek_food 远程 / 远距离 mine_nearby
跨水长途 / 首次探索 / 新长链
```

## 5. 防 ADHD / 发愣

- 段内只换原子，不换目标；
- 切换带收尾/理由，段边界才重规划；
- 空 plan 必须落基线行为（守夜/整理/盘点/恢复）；
- 每段目标数量 1–2 个，不并行开五个头；
- 一天只有 5–6 个可用段，“一天只干成一件事”是正常的。

## 6. 验收

通过：

```text
黄昏 11000–13000 只出现即时项
入夜 13000–23000 无 outdoor 长任务 atom
深夜有低警戒恢复，不是全程守夜/踱步
段切换有 phase_change{from,to,reason}
```

判负：

```text
黄昏出现新采集/远行 atom
入夜出现户外长任务 atom
夜间“离开16格→返回”循环且无硬信号 reason ≥1 次
段内换生产目标且无阶段边界
任意 5–10s 无动作且 trace 无 reason
```

## 7. 与 P0 的边界

```text
P0 不动：DispatchGate / actionLock / latch / 状态机
本规划只改：候选生成、时间段策略、基线行为
```

## 8. 一句话

```text
时间不是命令，是窗口；
行为不是清单，是“这段够不够安全/够不够时间”的选择。
```
