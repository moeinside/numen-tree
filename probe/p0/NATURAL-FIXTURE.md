# P0 自然夹具（随机新档）

> 不手工放资源。新开随机世界，用扫描选点/记录；作弊扫描只用于夹具选点与记录，不作为运行时感知。

## 最小条件

- 新世界：生存 / 普通难度 / 随机种子（固定种子更好，但不强求）；
- 同伴在出生点附近；
- 树运行，无 LLM 任务，玩家不干预；
- 允许我们用只读扫描找附近木头/水/动物/矿；
- 允许一次性 `/tp` 把同伴放到扫描选出的位置（如果出生点太差）。

## 验收口径（自然世界版）

自然世界不能保证“3 铁 1 煤 + 1 树”同时出现，所以 P0 验收改为：

1. 无 LLM 活过两夜；
2. 死亡 ≤1，且死亡后能从 milestone 继续；
3. 计划不空转（同因重试 ≤3，无“忙而无进度”>90s）；
4. resume 抖动 ≤2 次/分钟；
5. 已发现的可用资源能推进 ≥1 个 milestone；
6. 夜间室外任务 =0；
7. 记录世界种子、出生点、扫描到的资源清单，便于复现。
