# P0 审计与固定夹具

## 目的

先证明审计**会判负**，再改树行为。  
不采信执行器自报；所有结论来自外部快照 + 观测 + trace + 审计脚本。

## 文件

- `audit.mjs`：纯函数审计核心；
- `audit-selftest.mjs`：负样本演练（10 项）；
- `fixture-spec.json`：P0 固定世界规格与冻结清单。

## 负样本（必须全部判负）

1. 执行器自报成功，但世界没变；
2. 谓词由执行器自评；
3. 快照被篡改/缺哈希；
4. stale fact 被使用；
5. unknown 被当 false；
6. 状态改变后未复观测；
7. resume 无成功观测/循环；
8. 观察超预算；
9. 阈值未冻结。

## 运行

```bash
node probe/p0/audit-selftest.mjs
```

通过标准：正样本通过；九个负样本全部被对应 code 判负。
